# 04 · 构图推导

> 读这份的时机：读完 `02-排版思想.md` + `03-杠杆点.md`，准备写坐标之前。
> 这里不提供模板；只把前两份的原则落成五个决定和区域。

## 一、先写构图意图

不要先选模板，也不要先数图。先回答五个问题：

| 决定 | 选项 | 回答什么 |
|---|---|---|
| **主角** | 文字 / 图像 / 图形 / 数字 | 第一眼必须看到谁？ |
| **图文关系** | 分离 / 并置 / 叠压 / 嵌入 | 文字和图像怎么相处？ |
| **骨架** | 满幅 / 分栏 / 网格 / 自由 | 版面靠什么组织？ |
| **阅读路径** | 上→下 / 左→右 / 中心向外 / 对角线 | 视线按什么顺序走？ |
| **张力** | 守格 / 破格 / 出血 / 重叠 / 大小对比 | 哪一处故意不一样？ |

把这五个答案写成一句话，例如：

> 主角是产品；图文并置；2:3 分栏；视线从标题走到右下产品；张力在标题压出左边界。

**图的数量是结果，不是起点**：先定内容任务和关系，最后再核对 0 / 1 / 2+ 是否成立。
**结构没有名字**：同一组答案可以长出不同版式；不要套固定模板，也不要按编号轮换。

## 二、从意图到区域

先分**大块**，再分**文字块**，最后才写具体坐标。

1. **主角区**先占位：给它最大、最安静、最亮或最居中的一块；其他元素围绕它让位。
2. **图文区**按关系分：
   - **分离**：文字和图各占一块，互不重叠；适合信息清楚、阅读优先的内容。
   - **并置**：左右或上下并列；适合对比、前后、双主体。
   - **叠压**：文字压在图上；适合氛围、单主体，但必须先找到素材的安静区。
   - **嵌入**：小图嵌入大图或文字区；适合局部、细节、材质证明。
3. **骨架线**最后定：边距、栏宽、基线、对齐线。先保证同类元素互相对齐，再谈破格。
4. **张力**只留 1–2 处：让主角去破格、出血或压边；不要让次要元素抢这个戏。

> 先问“这块区域承担什么任务”，再问“它放在哪”。区域的任务说不清，坐标再准也只是装饰。

## 三、边距与主次

- 页边距通常 **6–8%**；主体可以贴边，但文字不要贴边。
- 主角占画面 **50–65%** 是常见区间；超过 70% 容易压掉其他信息，低于 40% 容易显得空。
- 相邻尺寸优先用 **黄金比例（1 : 1.618）**；并置对比可以用 **1 : 2 / 2 : 3**，不要默认 50 / 50。
- 网格、字号四档、间距四档见 `02-排版思想.md`；这里不再重复。

## 四、文字压图与内嵌

### 文字压图：先找安静区

文字放在素材的**暗部 / 天空 / 桌面**，不要默认放顶部。主体在中间时，
把文字放到下方安静区，别用顶部压暗层把主体一起压掉。

> 压暗层的高度、渐变、对比度做法见 `06-外观与对比.md`；构图阶段只负责选对安静区。

### 内嵌图

- 不要「深色底矩形 + 细描边」浮在大图上——像贴了一块黑框；
- 要么**贴边**：至少贴住一条画布边（右 / 上 / 下），读成裁切延伸；
- 要么**做成卡片**：给明确底色 / 纸感 / 框，且内嵌图背景与框色一致。

## 五、换画布比例

以上比例按竖版（4:5 / 3:4）调。换比例时只动字号和文字块，不重画骨架：

| 比例 | 标题字号 | 正文 | 文字块 |
|---|---|---|---|
| `9:16` | 原样，可再放大一档 | 原样 | 不用挪 |
| `1:1` | × 0.75 | × 0.9 | 不用挪 |
| `16:9` | × 0.55 | × 0.8 | 整体上移 0.05–0.1 |

横版高度小，原字号会顶到下一行——**换比例必须重算字号**；字号档位见 `02-排版思想.md`。

## 六、变体与偏离

- 先改变**比例、边距、对齐**；不够再改图文关系或骨架。
- 每套设计允许 **1–2 处故意偏离**，但只能让主角去偏。
- 同套图不要按固定模板轮换；按**阅读路径 / 主角类型**错开。
- 不要用“换骨架”逃避内容问题：区域的任务没变，换骨架也不会让画面更清楚。

## 七、验收

1. 能用一句话说出构图意图吗？（主角 / 关系 / 骨架 / 阅读路径 / 张力）
2. 缩到 20%，第一眼看到的是主角吗？
3. 文字在素材的安静区吗？
4. 字号、间距、网格按 `02-排版思想.md` 检查了吗？
5. 有哪一处是故意偏离的？它服务主角吗？
6. 同套图的阅读路径 / 主角类型错开了吗？
