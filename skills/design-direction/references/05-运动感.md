# 05 · 运动感

> 读这份的时机：**画面太静、像说明书、缺"动势"**时。
> 运动感不是动画，是**静止画面里的方向与节奏**——让眼睛沿着一条线走，
> 而不是在一个个方块之间跳。

## 一、五种手段

| 手段 | 怎么在静止画面里做 | 在草图里 |
|---|---|---|
| **递进** | 同类元素尺寸逐级变化（0.06 / 0.09 / 0.135 ≈ 1 : 1.5 : 2.25） | ✅ 尺寸 |
| **缩放对比** | 一大一小并置，制造前后/主次 | ✅ 尺寸 |
| **方向性** | 让一组元素朝同一方向倾斜 | ⚠️ 见 §三 |
| **重复** | 同一元素等距重复，形成条带 / 节奏 | ✅ 多个同尺寸元素 |
| **模糊 / 运动模糊** | 景深、拖影、速度感 | ❌ 不做图形，交给素材阶段 |

**一次用一种。** 同时用递进 + 方向 + 重复，画面会变成噪音。

## 二、递进与缩放对比（草图阶段最可用）

**递进**：三个同类的块，尺寸按 1 : 1.5 : 2.25 递增/递减，视线会自然从大到小走。

| 块 | 左 | 上 | 宽 | 高 |
|---|---|---|---|---|
| A | .06 | .10 | .18 | .18 |
| B | .06 | .32 | .14 | .14 |
| C | .06 | .50 | .10 | .10 |

**缩放对比**：一个大的主体 + 一个明显小的参照（硬币、手、A4 纸），
既做层级，又暗示"真实尺寸"。

⚠️ 递进要**同方向**（都变大或都变小），不要一大一小再一大——那是乱。

## 三、方向性：倾斜

**设计意图**：让一组元素朝同一方向倾斜（5°–15°），画面立刻有"风"或"动势"。
倾斜方向要一致，不能一个左一个右。

**落地方式**：

- **优先用不依赖旋转的两种近似**：
  1. **斜向排列**：不转元素，让一组元素沿对角线排（左增加、上也增加）；
  2. **阶梯缩进**：每个元素比上一个多缩进 `.02–.03`，形成斜向节奏。
- 如果当前媒介支持旋转，再让一组装饰 / 图形 / 图片**同方向**倾斜 5°–15°；
- 文字不一定要转：标题用斜向排列或阶梯缩进就能获得方向感，不要为了旋转牺牲可读性。

## 四、重复

同一元素等距重复（图标、色块、细线、标签），形成条带或节奏。
重复的关键是**间距一致**（用 `tight` / `group` 档），
不一致的重复看起来像没对齐。

重复也可以用来做"运动"：一排元素从左到右逐渐变大/变小，
就是最便宜的递进。

## 五、模糊 / 运动模糊：不要用图形假装

- 景深、拖影、速度线、光束 → **交给素材阶段**，让素材自带；
- 不要用半透明色块 / 细线去"画"模糊——看起来是脏的，不是虚的；
- 如果素材没有动感，宁可不用运动感，也不要用图形硬凑。

## 六、自检

1. 画面的"动"是往哪个方向？这个方向是否指向**杠杆点**？
2. 用的是哪一种手段？（递进 / 缩放对比 / 方向 / 重复）有没有混用？
3. 倾斜是不是只有一个方向？角度在 5°–15° 内吗？
4. 运动感有没有抢过主角？（比如一组斜排的装饰比大图还显眼）
5. 如果去掉运动感，画面是否更清楚？是 → 去掉。

## 七、反例

- 每个元素都转一点，角度各不相同 → 乱，不是动；
- 用"斜切色块"当背景，但主体是正的、文字是正的 → 方向性不成立；
- 递进用了三次不同比例（1 : 1.2 : 1.7）→ 看不出节奏，只是大小不一；
- 在同一张图里同时用递进 + 倾斜 + 重复 → 视觉噪音。
