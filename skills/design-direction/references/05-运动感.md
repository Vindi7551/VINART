# 05 · 运动感

> 读这份的时机：**画面太静、像说明书、缺"动势"**时。
> 运动感不是动画，是**静止画面里的方向与节奏**——让眼睛沿着一条线走，
> 而不是在一个个方块之间跳。

## 一、五种手段

| 手段 | 怎么在静止画面里做 | 在 plan 里 |
|---|---|---|
| **递进** | 同类元素尺寸逐级变化（0.06 / 0.09 / 0.135 ≈ 1 : 1.5 : 2.25） | ✅ `rect.w/h` |
| **缩放对比** | 一大一小并置，制造前后/主次 | ✅ `rect.w/h` |
| **方向性** | 让一组元素朝同一方向倾斜 | ⚠️ 见 §三（草图暂不支持 rotate） |
| **重复** | 同一元素等距重复，形成条带 / 节奏 | ✅ 多个同尺寸节点 |
| **模糊 / 运动模糊** | 景深、拖影、速度感 | ❌ 不做节点，归**生图提示词** |

**一次用一种。** 同时用递进 + 方向 + 重复，画面会变成噪音。

## 二、递进与缩放对比（草图阶段最可用）

**递进**：三个同类的块，尺寸按 1 : 1.5 : 2.25 递增/递减，视线会自然从大到小走。

```
块 A  x .06 y .10 w .18 h .18
块 B  x .06 y .32 w .14 h .14
块 C  x .06 y .50 w .10 h .10
```

**缩放对比**：一个大的主体 + 一个明显小的参照（硬币、手、A4 纸），
既做层级，又暗示"真实尺寸"。

⚠️ 递进要**同方向**（都变大或都变小），不要一大一小再一大——那是乱。

## 三、方向性：倾斜

**设计意图**：让一组元素朝同一方向倾斜（5°–15°），画面立刻有"风"或"动势"。
倾斜方向要一致，不能一个左一个右。

**当前落地方式**（重要）：

- `sketch_plan` 的 schema **不接收 `transform`**，所以草图阶段写不出旋转；
- 草图之后：
  - **image / svg / shape**：用 `patch_doc` 的 `rotate`（度）直接落；
  - **text**：第一版 `patch_doc` 不接受文字旋转，只能在编辑器里手动转；
- 如果不想转元素，还有两种近似：
  1. **斜向排列**：不转元素，让一组元素沿对角线排（x 增加、y 也增加）；
  2. **阶梯缩进**：每个元素比上一个多缩进 `.02–.03`，形成斜向节奏。

> ⚠️ 不要在 plan 里写 `transform`——schema 会拒掉，浪费一轮。

## 四、重复

同一元素等距重复（图标、色块、细线、标签），形成条带或节奏。
重复的关键是**间距一致**（用 `tight` / `group` 档），
不一致的重复看起来像没对齐。

重复也可以用来做"运动"：一排元素从左到右逐渐变大/变小，
就是最便宜的递进。

## 五、模糊 / 运动模糊：不要用节点假装

- 景深、拖影、速度线、光束 → **写在生图提示词里**，让素材自带；
- 不要用半透明色块 / 细线节点去"画"模糊——渲染出来是脏的，不是虚的；
- 如果素材没有动感，宁可不用运动感，也不要用节点硬凑。

## 六、自检

1. 画面的"动"是往哪个方向？这个方向是否指向**杠杆点**？
2. 用的是哪一种手段？（递进 / 缩放对比 / 方向 / 重复）有没有混用？
3. 倾斜是不是只有一个方向？角度在 5°–15° 内吗？
4. 运动感有没有抢过主角？（比如一组斜排的装饰比主图还显眼）
5. 如果去掉运动感，画面是否更清楚？是 → 去掉。

## 七、反例

- 每个元素都转一点，角度各不相同 → 乱，不是动；
- 用"斜切色块"当背景，但主体是正的、文字是正的 → 方向性不成立；
- 递进用了三次不同比例（1 : 1.2 : 1.7）→ 看不出节奏，只是大小不一；
- 在同一张图里同时用递进 + 倾斜 + 重复 → 视觉噪音。
