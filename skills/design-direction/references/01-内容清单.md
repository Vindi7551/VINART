# 01 · 内容清单与形式选择

> 读这份的时机：**每次开始设计之前**。先决定“要说什么”，再决定“用什么形式”，
> 最后才是“几个图”。图的数量是结果，不是起点。

## 一、先把内容摊开，不套栏目

不要先填“标题 / 副标 / 日期 / CTA”模板。先把**这次 brief 里实际存在的东西**全部摊开：

- 用户给的原文、必须逐字保留的句子；
- 用户给的素材（照片 / 插画 / 图形 / 纹理）；
- 你判断需要补充的词、数字、名单、引用；
- 甚至一个词、一个数字、一块色、一片留白。

**没有哪一类信息是必须的。** 一张海报可以只有一句话；一张封面可以只有一个图像；
一张信息图可以没有标题。清单是**开集**，不是检查表。

拿不准某条要不要留，可以问（不是审批）：

1. 它在这张画面里承担什么？
2. 它和主角是什么关系？
3. 去掉它，画面会更清楚，还是更空？

**表达性内容不需要“证明有用”**：一块色、一条线、一处留白，只要它有意图，就可以留下。

## 二、再选载体，不选角色

| 载体 | 适合承载 |
|---|---|
| 文字 | 标题、引语、正文、数据标签、名单 |
| 照片 | 需要“真实外观 / 现场 / 质感”的信息 |
| 插画 | 需要手绘 / 风格化 / 非写实的内容 |
| 图形 | 几何、色块、分隔、底、装饰 |
| 数据图 | 数字、比例、趋势、对比 |
| 留白 | 隔离、节奏、呼吸——**也是载体** |

**不需要给内容分配固定角色。**
一条信息可以：

- 只用文字；
- 文字 + 一张图；
- 一组图形；
- 纯留白（“安静”本身也可以是一条信息）。

## 三、排优先级

- **主角：1 个**（标题 / 主体 / 一个数字 / 一张图）；
- **次级：1–2 个**；
- **注记：其余**。

没有主角 = 平；所有都是主角 = 没有主角。

## 四、内容清单（给用户看）

> ⚠️ **硬门**：这次要用的内容没摊开给用户看，**不进入落版**。
> 不需要凑栏目；哪怕只有一句话、只有一个词，也先摊开。
> 用户说「直接做 / 不用问」时也一样——先发一条，再画草图。

> 下面只是示例，不是必须填的栏目；内容可以比这多，也可以比这少。

| 内容 | 优先级 | 载体 | 备注 |
|---|---|---|---|
| 展览名「生命体征」 | 主角 | 文字 | 大字号，上半屏 |
| 一句话解释 | 次级 | 文字 | 标题下 |
| 日期 / 地点 | 注记 | 文字 | 底部左右 |
| 作品照片 | 配角 | 照片 | 右侧竖图，可选 |
| 艺术家名单 | 注记 | 文字 | 8 人小网格 |

列的是**内容**，不是“图位”。没有图的条目也照样列。

### 0 图：字体主视觉

| 内容 | 优先级 | 载体 | 备注 |
|---|---|---|---|
| 展览名 + 日期 | 主角 | 文字 | 大字号压住上半屏 |
| 一条细线 / 一个小色块 | 次级 | 图形 | 做分隔，不抢标题 |

### 1 图：文字 + 一张照片

| 内容 | 优先级 | 载体 | 备注 |
|---|---|---|---|
| 标题 + 引语 | 主角 | 文字 | 左栏纵向 |
| 展厅现场 | 配角 | 照片 | 右侧整栏，贴边 |

### 多图：展览 / 演出

| 内容 | 优先级 | 载体 | 备注 |
|---|---|---|---|
| 主视觉照片 | 配角 | 照片 | 占画面一半以内 |
| 局部照片 | 注记 | 照片 | 小图，和主视觉同一场景/光线 |
| 标题 / 日期 / 地点 | 主角 | 文字 | 仍要有一个文字主角 |

**“内容”必须能直接变素材要求或排版指令**：

```
主体 + 视角 + 背景 + 光线
```

反例：「温暖的氛围」「高级感」「有设计感」——不是内容，模型只能猜。
正例：「展厅中央的装置作品，观众从旁边经过，水泥地面，左侧窗光」。

## 五、形式选择

- **能纯文字成立，就不要硬塞图**；
- 需要真实外观 → 照片；需要风格化 → 插画；需要关系/比例 → 图表或几何；
- 图片数量按内容任务定：0 / 1 / 2+ 都可能；
- **只有照片 / 插画内容项消耗素材生成**；文字、图形、留白不消耗。

## 六、反例

- 先问“几个图”，再想内容；
- 给每条信息硬塞一个图；
- 用“氛围 / 高级感”当内容；
- 所有信息同一优先级；
- 为了“画面不空”硬塞一张照片；
- 每个设计都默认 3 张图；
- 内容清单里写“主图 / 细节图”，却说不清它回答什么问题。

## 七、和 listing 的关系

listing 只是一种内容类型：先按本文件列内容、定优先级、选载体，
再用 listing 的合规规则补细节。**内容清单是通用的，listing 只负责内容与顺序。**
