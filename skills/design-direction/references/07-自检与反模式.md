# 07 · 自检与反模式

> 读这份的时机：**提交前**；或用户说"还是很单调/很平/很空"时，先对着这里定位。

## 一、落版之前

- [ ] 内容清单列全了吗？每条都有优先级和载体吗？
- [ ] 0 / 1 / 2+ 是内容任务决定的吗？（没有「必须几个」）
- [ ] 每条内容任务都不同、都能直接变素材要求或排版指令吗？
- [ ] 选的是哪个结构？图数和结构对得上吗？
- [ ] 同套图里结构错开了吗？同一结构连用 ≤2 张？
- [ ] 主角是谁？写下来了吗？
- [ ] 主角比第二重要的元素大 ≥1.3 倍吗？周围有 `section` 档留白吗？
- [ ] 字号有 3–4 级、相邻档差 1.5–2 倍吗？
- [ ] 间距有档差（不是全篇等距）吗？
- [ ] 所有位置 / 尺寸都用画布比例表达了吗？文字只定了左 / 上 / 宽吗？
- [ ] 草图阶段只决定结构 / 位置 / 占位，没有写颜色 / 字体 / 阴影 / 旋转吗？

## 二、调外观之前

- [ ] 先读当前版式，确认要改的元素了吗？
- [ ] 四个颜色角色（背景/墨色/强调/弱化）定了吗？
- [ ] 强调色只给主角/CTA 吗？
- [ ] 文字压图有 scrim 吗？对比度 ≥4.5:1 吗？
- [ ] 字体最多两个字族吗？
- [ ] **scrim 只盖文字带**（.30–.45），没有把主体一起压掉吗？
- [ ] 文字区在素材的安静区，不在主体上吗？
- [ ] 标题该上的效果上了吗？（压图时白字无描边 / 无 scrim / 全篇同字重 = 平）
- [ ] 内嵌图是贴边或做成卡片，不是深色底矩形浮在大图上吗？

## 三、交给用户之前

- [ ] 眯眼/缩到 20%：第一眼看到的是主角吗？
- [ ] 视线能按"主 → 次 → 注记"走完吗？
- [ ] 有没有"近似对齐"（差 0.03 那种）？要么对齐，要么明显错开。
- [ ] 有没有元素既不加清晰度、也不服务主角？删。
- [ ] 一套图里风格统一、但每张构图不同吗？
- [ ] 用户能说出"这张图想让我看什么"吗？
- [ ] **回复里的数字和当前版式对得上吗？** 不要说"紧贴 / 成倍数 / 对齐"而实际不是；先读当前版式自查。
- [ ] **没有承诺未落地的改动**吗？

## 四、反模式（出现任意一条就不合格）

| # | 反模式 | 为什么错 | 改法 |
|---|---|---|---|
| 1 | 只有一块内容 + 一堆同级文字 | 没有信息层级 | 回 01，补上缺失的内容项 |
| 2 | 用色块 + 文字冒充细节/证据 | 是"声称"，不是"证明" | 换成独立内容项（文字 / 照片 / 图形） |
| 3 | 同套图所有结构一样 | 8 张长一样 = 一套模板 | 02 里错开结构 + 变体 |
| 4 | 两条内容是同一件事换框 | 任务重复，浪费一个内容项 | 换任务或砍掉 |
| 5 | 全篇一个字号 | 没有层级 | 03 的四档，相邻 1.5–2 倍 |
| 6 | 间距全篇等距 | 没有分组、没有节奏 | 03 的四档间距 |
| 7 | 每个元素都强调（颜色/框/尺寸） | 等于没有强调 | 04，只留一个主角 |
| 8 | 默认"干净留白"把主体缩小 | 空 ≠ 高级 | 01/03，主体占够、留白做隔离 |
| 9 | 用满幅几何块当背景 | 背景是画布底色的事 | 用画布底色 |
| 10 | 一次生成 4 张图却不先给内容清单 | 用户没机会拦 | 先内容清单，再进素材阶段 |
| 11 | 画面很"满"但找不到主角 | 缺杠杆点 | 04 的缩放/隔离/定位 |
| 12 | scrim 盖到主体 / 高度 .60 / 硬边 | 主体被压暗、主次反转 | 02 的 text-bottom + 渐变；只盖文字带 |
| 13 | 最终回复承诺未落地的改动 | 用户会按错误信息验收 | 先看当前版式，别承诺没做的改动 |
| 14 | 回复声称"紧贴/成倍数"但实际不是 | 用户会按错误信息验收 | 先读当前版式对数字 |

## 五、"单调"快速诊断

| 症状 | 大概率缺什么 | 先读 |
|---|---|---|
| 只有一块内容，剩下全是同级文字 | 信息层级 | 01 |
| 每张构图长得一样 | recipe 错开 / 变体 | 02 |
| 画面平，不知道看哪 | 杠杆点 | 04 |
| 元素像表格、视线乱 | 节奏 / 分组 / 网格 | 03 |
| 画面太静、像说明书 | 运动感 | 05 |
| 颜色素、没重点 | 对比 / 强调色 | 06 |
| 主体太小、四周空 | 构图 / 留白误用 | 02 + 03 |

## 六、只能改一处时，按这个顺序

1. **加一条内容项**（如果它真的承担独立任务）；
2. **定一个主角**，把它放大 1.3 倍以上、周围留 `section`；
3. **拉开字号档差**（标题 .09 / 副 .03 / 标签 .016）；
4. **让间距有档差**（组内 .022，组间 .085）；
5. **给主角一个强调色**（只给它）；
6. 最后才考虑旋转 / 重叠 / 装饰。

前四步做完，画面通常已经不单调了；后两步是加分项。
