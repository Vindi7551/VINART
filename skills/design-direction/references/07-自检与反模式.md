# 07 · 自检与反模式

> 读这份的时机：**提交前**；或用户说"还是很单调/很平/很空"时，先对着这里定位。

## 一、落版之前

- [ ] 内容清单列全了吗？每条都有优先级和载体吗？
- [ ] 0 / 1 / 2+ 是内容任务决定的吗？（没有「必须几个」）
- [ ] 每条内容任务都不同、都能说清它在画面里承担什么吗？
- [ ] 构图意图是什么？主角 / 图文关系 / 骨架说得清吗？
- [ ] 同套图里阅读路径 / 主角类型错开了吗？
- [ ] 主角是谁？写下来了吗？
- [ ] 主角比第二重要的元素大 ≥1.3 倍吗？周围有 `section` 档留白吗？
- [ ] 字号有 3–4 级、相邻档差 1.5–2 倍吗？
- [ ] 间距有档差（不是全篇等距）吗？
- [ ] 所有位置 / 尺寸都用画布比例表达了吗？文字只定了左 / 上 / 宽吗？
- [ ] 草图阶段只决定区域 / 位置 / 占位，没有写颜色 / 字体 / 阴影 / 旋转吗？

## 二、调外观之前

- [ ] 先读当前版式，确认要改的元素了吗？
- [ ] 四个颜色角色（背景/墨色/强调/弱化）定了吗？
- [ ] 强调色只给主角/CTA 吗？
- [ ] 文字压图有 scrim 吗？对比度 ≥4.5:1 吗？
- [ ] 字体最多两个字族吗？
- [ ] **scrim 只盖文字带**（.30–.45），没有把主体一起压掉吗？
- [ ] 文字区在素材的安静区，不在主体上吗？
- [ ] 标题该上的效果上了吗？（压图时白字无描边 / 无 scrim / 全篇同字重 = 平）
- [ ] 内嵌图是贴边或做成卡片，不是深色底矩形浮在大图上吗？

## 三、可访问性硬指标

下面是一组常见基线（WCAG 2.2 AA 方向）；具体项目按目标标准/平台规范确认。
这些是**设计约束**，不是最后才补的检查项。

| 项目 | 最低要求 | 怎么做 |
|---|---|---|
| **正文对比度** | ≥ 4.5:1 | 用对比度工具测；不要四舍五入 |
| **大文本对比度** | ≥ 3:1（≥18pt，或 ≥14pt 粗体） | 标题也不能糊 |
| **非文本对比度** | ≥ 3:1（图标/控件/状态） | 图标、边框、焦点框都要测 |
| **不只靠颜色** | 颜色不能是唯一信息载体 | 加图标、文字、图案、下划线 |
| **文字间距** | 用户调整后不丢内容：行高 1.5×、段距 2×、字距 0.12em、词距 0.16em | 容器不要写死高度；允许换行 |
| **触控目标** | 至少 24×24 CSS px（或有足够间距） | 移动端更建议 44×44 |
| **键盘焦点** | 必须可见 | 不要 `outline: none` 了事 |
| **图片替代** | 有意义的图有 alt；装饰图 alt 为空 | 图表给文字摘要/数据表 |
| **动效** | 提供暂停/减少动态 | 不要自动播放声音 |
| **文字成图** | 尽量避免 | 图片里的文字不能选中/缩放/换色 |

**颜色盲检查**：红绿不要作为唯一区分；用明度/形状/文字辅助。
**文字压图**：按最差区域测对比，不要只测平均；渐变/半透明背景尤其要小心。

## 四、交给用户之前

- [ ] 眯眼/缩到 20%：第一眼看到的是主角吗？
- [ ] 灰度下层级还成立吗？去掉颜色后会不会糊成一片？
- [ ] 缩到缩略图 / 看 5 秒：能说出这是什么、下一步看哪吗？
- [ ] 文案变长 / 换语言 / 换比例，布局还成立吗？
- [ ] 视线能按"主 → 次 → 注记"走完吗？
- [ ] 有没有"近似对齐"（差 0.03 那种）？要么对齐，要么明显错开。
- [ ] 有没有元素既不加清晰度、也不服务主角？删。
- [ ] 一套图里风格统一、但每张构图不同吗？
- [ ] 用户能说出"这张图想让我看什么"吗？
- [ ] **回复里的数字和当前版式对得上吗？** 不要说"紧贴 / 成倍数 / 对齐"而实际不是；先读当前版式自查。
- [ ] **没有承诺未落地的改动**吗？

## 五、评审：10 项评分

给自己或他人打分（1–5），每一项写一句“为什么”，不要只说“好看/不好看”。

| # | 维度 | 问题 |
|---|---|---|
| 1 | **目的/信息** | 这张设计要让受众知道/做什么？一句话说清了吗？ |
| 2 | **层级/主角** | 第一眼看到的是主角吗？主→次→注记清楚吗？ |
| 3 | **构图/平衡** | 画面稳定或有意图地紧张？视线路径顺吗？ |
| 4 | **字体** | 字号/行宽/行距/对齐/搭配可读、成体系吗？ |
| 5 | **色彩** | 角色清楚？对比够？强调克制？ |
| 6 | **图像** | 图像服务内容？质量/裁切/图底关系？ |
| 7 | **一致性** | 同套图/同品牌统一吗？ |
| 8 | **可访问性** | 对比/字号/颜色/焦点/触控/替代文本？ |
| 9 | **制作** | 边缘/对齐/出血/分辨率/细节？ |
| 10 | **适配/原创** | 适合受众/媒介？有记忆点但不抄？ |

评分不是目的；**低分项就是下一轮改动的优先级**。

## 六、反模式（出现任意一条就不合格）

| # | 反模式 | 为什么错 | 改法 |
|---|---|---|---|
| 1 | 只有一块内容 + 一堆同级文字 | 没有信息层级 | 回 01，补上缺失的内容项 |
| 2 | 用色块 + 文字冒充细节/证据 | 是"声称"，不是"证明" | 换成独立内容项（文字 / 照片 / 图形） |
| 3 | 同套图所有构图一样 | 8 张长一样 = 一套模板 | 按阅读路径 / 主角类型错开 + 变体 |
| 4 | 两条内容是同一件事换框 | 任务重复，浪费一个内容项 | 换任务或砍掉 |
| 5 | 全篇一个字号 | 没有层级 | 02 的四档，相邻 1.5–2 倍 |
| 6 | 间距全篇等距 | 没有分组、没有节奏 | 02 的四档间距 |
| 7 | 每个元素都强调（颜色/框/尺寸） | 等于没有强调 | 03，只留一个主角 |
| 8 | 默认"干净留白"把主体缩小 | 空 ≠ 高级 | 01/02，主体占够、留白做隔离 |
| 9 | 用满幅几何块当背景 | 背景是画布底色的事 | 用画布底色 |
| 10 | 一次要 4 张图却不先给内容清单 | 用户没机会拦 | 先内容清单，再安排画面 |
| 11 | 画面很"满"但找不到主角 | 缺杠杆点 | 03 的缩放/隔离/定位 |
| 12 | scrim 盖到主体 / 高度 .60 / 硬边 | 主体被压暗、主次反转 | 04 的安静区 + 06 的渐变；只盖文字带 |
| 13 | 最终回复承诺未落地的改动 | 用户会按错误信息验收 | 先看当前版式，别承诺没做的改动 |
| 14 | 回复声称"紧贴/成倍数"但实际不是 | 用户会按错误信息验收 | 先读当前版式对数字 |

## 七、"单调"快速诊断

| 症状 | 大概率缺什么 | 先读 |
|---|---|---|
| 只有一块内容，剩下全是同级文字 | 信息层级 | 01 |
| 每张构图长得一样 | 阅读路径 / 主角类型错开 | 04 |
| 画面平，不知道看哪 | 杠杆点 | 03 |
| 元素像表格、视线乱 | 节奏 / 分组 / 网格 | 02 |
| 画面太静、像说明书 | 运动感 | 05 |
| 颜色素、没重点 | 对比 / 强调色 | 06 |
| 主体太小、四周空 | 构图 / 留白误用 | 04 + 02 |

## 八、只能改一处时，按这个顺序

1. **加一条内容项**（如果它真的承担独立任务）；
2. **定一个主角**，把它放大 1.3 倍以上、周围留 `section`；
3. **拉开字号档差**（标题 .09 / 副 .03 / 标签 .016）；
4. **让间距有档差**（组内 .022，组间 .085）；
5. **给主角一个强调色**（只给它）；
6. 最后才考虑旋转 / 重叠 / 装饰。

前四步做完，画面通常已经不单调了；后两步是加分项。

## 九、不要把启发式当定律

这些都是**常用启发式**，不是审美定律。用之前先问：它是否服务这张图的目标？

- **黄金比例**：有用，但不是“美的定律”；很多好设计不用它。
- **三分法**：不是必须；中心构图、对称构图同样可以很强。
- **色彩心理**：受文化/行业/语境影响；没有“蓝色=信任”的普适公式。
- **衬线 vs 无衬线**：没有绝对优劣；高分辨率屏幕上衬线体完全可以读。
- **留白越多越高级**：不是。留白要服务分组/层级/呼吸；主体太小 + 大片空 = 稀疏。
- **极简 = 少东西**：不是。极简是用更少的元素建立更强的秩序。
- **网格是死板的**：不是。网格是脚手架；好的设计大部分守格、少数破格。
- **对称 = 无聊**：不是。对称可以正式、稳定、有仪式感。
- **全大写 = 高级**：短标签可以；长文全大写会降低阅读速度。
- **两端对齐 = 专业**：书籍/报纸可以；屏幕正文两端对齐容易产生河流。
- **字体越多越丰富**：通常不是。两个字族 + 多字重已经够。
- **设计是纯主观的**：审美有主观成分，但设计可以按目标、受众、可用性、可访问性、制作质量评估。

> 原则是“在大多数情况下让设计更容易被理解”，不是“违反就错”。
> 真正要守的是：**目标清楚、层级成立、可读、可访问、制作可靠**。
