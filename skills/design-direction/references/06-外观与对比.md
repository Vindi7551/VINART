# 06 · 外观与对比

> 读这份的时机：**草图定稿之后**（调外观阶段）；或用户说"配色不好看/太素/没重点"时。
> 草图阶段**不写颜色**——草图只决定区域与构图；颜色、字体、对比在这里做。

## 一、色彩是感知，不是装饰

| 属性 | 是什么 | 设计用途 | 注意 |
|---|---|---|---|
| **色相 hue** | 红/黄/蓝/绿等颜色种类 | 分类、情绪、品牌 | 色相不等于可读性 |
| **明度 value / lightness** | 明暗程度 | **可读性、层级、深度** | 先解决明度，再谈色相 |
| **饱和度 saturation / chroma** | 鲜艳/灰浊程度 | 强调、情绪强度、主次 | 大面积高饱和会累 |

**加色 vs 减色**：屏幕是 RGB（加色，叠加成白）；印刷是 CMYK（减色，叠加成黑）。
屏幕的亮色/荧光色，印刷往往印不出来；印刷的深色/金属色，屏幕也模拟不准。
跨媒介设计要**做色域检查/打样**，不要拿屏幕色直接当印刷色。

**色彩管理**：Web 以 sRGB 为基线，Display P3 色域更宽；印刷用 CMYK/专色。
同一组颜色在不同设备/纸上会变，重要项目要校准/打样。

## 二、四个颜色角色

一个画面只需要四个颜色角色，多一个都会乱：

| 角色 | 作用 | 占比 | 例 |
|---|---|---|---|
| **背景** | 定调，退到后面 | 60–70% | `#F7F3EA` 米白 / `#0E0C24` 深底 |
| **墨色** | 主文字，最高对比 | 20–25% | `#1A1A1A` / `#F5F0E6` |
| **强调** | 主角 / CTA / 关键数字 | 5–10% | 一个暖色或冷色 |
| **弱化** | 注记 / 分隔 / 次要信息 | 5–10% | 墨色的 40–60% 亮度 |

**60-30-10 原则**：背景 60、墨色 30、强调 10。强调色多了 = 没有强调。

需要更细的系统时，可以扩展成角色（不是颜色数量）：

| 扩展角色 | 用途 | 注意 |
|---|---|---|
| **表面 surface** | 卡片、面板、分区 | 与背景有轻微明度差 |
| **次级文字** | 说明、注记 | 对比略低，但不能读不清 |
| **语义色** | 成功/警告/错误/信息 | 不能只靠颜色，配图标/文字 |
| **禁用/弱化** | 不可用、次要 | 仍要能辨认 |

## 三、对比的六种类型（都服务于层级）

| 类型 | 怎么做 | 用在哪 |
|---|---|---|
| **明度对比** | 深底浅字 / 浅底深字 | 主文字，保证可读 |
| **色相对比** | 冷底 + 暖强调（或反过来） | 让主角跳出来 |
| **饱和度对比** | 大面积低饱和 + 小面积高饱和 | 强调色只在主角上 |
| **面积对比** | 大块安静 + 小块强烈 | 主角占比小但更亮 |
| **冷暖对比** | 背景冷、主体暖 | 产品/人物更突出 |
| **虚实对比** | 背景压暗/去饱和，主体清晰 | 大图压在图上时 |

**同时对比**：同一个颜色放在不同背景上，看起来会不一样。
不要孤立地判断一个颜色“好不好看”，要放在它实际相邻的颜色里看。

**对比不是花哨，是让主角被看见。** 如果每个元素都在对比，等于没有对比。

## 四、配色方案

| 方案 | 做法 | 感觉 | 风险 |
|---|---|---|---|
| **单色** | 一个色相 + 明度/饱和度变化 | 统一、克制、容易高级 | 容易单调；靠明度/材质 |
| **邻近色** | 色轮上相邻 2–3 色 | 和谐、自然、柔和 | 对比弱；需要明度差 |
| **互补色** | 色轮相对两色 | 强对比、抢眼 | 容易刺眼；控制面积 |
| **分裂互补** | 一个主色 + 对面两侧 | 对比但更柔 | 颜色多，容易散 |
| **三角** | 色轮三等分 | 活泼、平衡、强对比 | 难控制；要选主色 |
| **四角** | 两组互补/四等分 | 丰富、复杂 | 容易乱；必须有主导 |

用法：**先定角色（背景/文字/强调），再选方案**。不要先挑六个颜色再想怎么用。

## 五、三个方向（给用户选，不要开放式提问）

| 方向 | 背景 | 墨色 | 强调 | 字体搭配 |
|---|---|---|---|---|
| **编辑感** | `#F7F3EA` 米白 | `#1A1A1A` | 一个暖色（赭石/砖红） | 高对比衬线标题 + 中性黑体正文 |
| **冷科技** | `#0E0C24` 深底 | `#F5F0E6` 浅字 | 冷紫 / 青 | 中性无衬线标题 + 正文 |
| **暖生活** | `#FDF8EF` 奶油 | `#3B2E25` 深棕 | 橙 / 绿 | 高对比衬线标题 + 中性黑体正文 |

⚠️ **具体字体从当前可用字体里选**：中文必须选**有中文字形**的字体；只有拉丁字形的展示体只用于英文短标题，不要拿去排中文，否则中文字形会变成别的字体。

字体最多**两个字族**：一个标题字体 + 一个正文字体。
标题用 600–900 字重，正文 400；**不要正文也用 900**——层级会糊。

## 六、文字压在图上：必须给可读性

> 文字区选在哪（素材安静区、放上还是放下）在构图阶段完成，见 `04-构图推导.md`；
> 这里只处理压暗层与对比度。

- 图上有文字时，先加**压暗层（scrim）**：一个矩形块覆盖文字区，
  填充半透明深色（如 55% 黑）；浅底图用半透明浅色；
- **不要用灰色实块**——灰块会变成"贴纸"，不是压暗；
- 文字与背景的对比度目标 **≥ 4.5:1**（正文）；标题可以略低，但不能糊；
- 压暗层要**只盖文字带**（通常 `.30–.45`），不是盖满全图，更不要 `.60` 把主体一起压掉；
- **优先用渐变**：从深到透明；整块实色会在边缘留一条硬边；
- **深色细节图放在暗背景上会糊在一起**：优先把它移到亮区（窗户 / 浅墙），
  或在图下面垫一个稍大的浅色矩形衬底（米白）当框——阴影只能辅助，不要靠阴影把暗图"抠"出来。

## 七、文字效果：该用就用

标题压在图上时，**白字 + 无处理 = 平**。可用：

- **描边**：深底浅字 / 浅底深字，只给标题；
- **阴影**：小偏移 / 小模糊，只给需要从背景里脱开的字；
- **渐变填充**：大标题用从亮到暗的线性渐变，小字不要；
- **色块 / 纸带**：用矩形色块垫在文字下，比阴影更稳；
- **字重 / 字号 / 字距**：最便宜的层级，先拉这个。

规则：**每个层级最多 1–2 种效果；正文不加；不要全篇描边 + 阴影 + 渐变一起上。**

## 八、把颜色接到层级上

1. **背景**最安静：低饱和、低对比；
2. **墨色**最高对比：正文可读；
3. **强调**只给杠杆点：主角、CTA、关键数字——**不要给每个标题都上强调色**；
4. **弱化**给注记：日期、地点、脚注，别和正文抢；
5. 一套图共享同一个配色：换图不换色，观众才认得出是"一套"。

## 九、白底纪律

- listing 主图：纯白底、无文字（平台硬约束）；
- 通用设计：**不要默认纯白**——米白 / 奶油 / 浅灰都比纯白有温度；
- 纯白只在"产品本身是白底、要极简"时用，而且要用**留白和层级**撑住，不能靠"空"。

## 十、深色模式与可访问性

**深色模式不是反色**：

- 不要纯白字 + 纯黑底；用略灰的白（如 `#E6E6E6`）和深灰（如 `#121212`）；
- 阴影在深色里效果弱，改用表面明度差/边框；
- 语义色要重新调，不要直接复用浅色模式；
- 对比度仍要满足 4.5:1 / 3:1。

**硬指标**：

- 正文对比度 **≥ 4.5:1**；大文本（≥18pt 或 ≥14pt 粗体）**≥ 3:1**；
- 非文本（图标/控件/状态）**≥ 3:1**；
- **不要只靠颜色**传达信息；用图标、文字、图案、下划线辅助；
- 颜色盲：红绿不要作为唯一区分；用明度/形状/文字；
- 文字压图按**最差区域**测对比，不要只测平均。

## 十一、自检

1. 四个颜色角色齐了吗？强调色是不是只出现在主角/CTA 上？
2. 明度对比够不够？灰度下层级还成立吗？
3. 颜色是不是太多？有没有一个主导色？
4. 文字压图时有没有 scrim？对比度够不够？
5. 字体是不是只有两个字族？正文有没有被标题字重污染？
6. 一套图里，背景/墨色/强调是不是同一套？
7. 深色模式/色盲/弱视下还成立吗？
