# 06 · 外观与对比

> 读这份的时机：**草图定稿之后**（调外观阶段）；或用户说"配色不好看/太素/没重点"时。
> 草图阶段**不写颜色**——草图只决定区域与构图；颜色、字体、对比、效果在这里做。

## 〇、色彩策略：先定为什么

不要先打开色轮。先写一句 **color brief**：

- **受众 / 场景 / 品类**：谁看？在货架、手机、展厅还是印刷品上看？
- **品牌位置**：保守/挑战、高端/亲和、专业/有趣；
- **情绪**：冷静、温暖、危险、安静、兴奋、可信；
- **对比需求**：要可读优先，还是戏剧性优先？
- **媒介**：屏幕、印刷、环境图形；色域/纸张/光线会改变颜色；
- **竞品**：要“像这个品类”，还是要“明显不同”？
- **可访问性**：对比、色盲、深色模式。

然后选**策略**（具体方案见 §四）：

| 策略 | 什么时候用 | 风险 |
|---|---|---|
| **单色** | 品牌色强、极简、要统一 | 单调；靠明度/材质 |
| **邻近色** | 要和谐、自然、柔和 | 对比弱 |
| **互补色** | 要冲突、焦点、叫卖 | 刺眼；要控制面积 |
| **分裂互补** | 要对比但不想太硬 | 颜色多，容易散 |
| **三角** | 要活泼、多角色 | 难控制；必须有主色 |
| **四角** | 要丰富、节庆、复杂 | 容易乱 |

**色彩系统**（不是一堆 hex）：

- 主色 / 辅色 / 中性色 / 语义色 / 强调色；
- 每个色相的 tint（加白）/ shade（加黑）/ tone（加灰）；
- 浅色/深色模式各一套角色，不是简单反色；
- 一套图共享同一套角色，换图不换色。

**色彩心理与文化的限制**：颜色联想受文化、行业、年龄、语境影响；
没有“蓝色=信任”的普适公式。把颜色当倾向，不当保证；用目标受众测试。

## 一、色彩是感知，不是装饰

| 属性 | 是什么 | 设计用途 | 注意 |
|---|---|---|---|
| **色相 hue** | 红/黄/蓝/绿等颜色种类 | 分类、情绪、品牌 | 色相不等于可读性 |
| **明度 value / lightness** | 明暗程度 | **可读性、层级、深度** | 先解决明度，再谈色相 |
| **饱和度 saturation / chroma** | 鲜艳/灰浊程度 | 强调、情绪强度、主次 | 大面积高饱和会累 |

**加色 vs 减色**：屏幕是 RGB（加色，叠加成白）；印刷是 CMYK（减色，叠加成黑）。
屏幕的亮色/荧光色，印刷往往印不出来；印刷的深色/金属色，屏幕也模拟不准。
跨媒介设计要**做色域检查/打样**，不要拿屏幕色直接当印刷色。

**色彩管理**：Web 以 sRGB 为基线，Display P3 色域更宽；印刷用 CMYK/专色。
同一组颜色在不同设备/纸上会变，重要项目要校准/打样。

## 二、四个颜色角色

一个画面只需要四个颜色角色，多一个都会乱：

| 角色 | 作用 | 占比 | 例 |
|---|---|---|---|
| **背景** | 定调，退到后面 | 60–70% | `#F7F3EA` 米白 / `#0E0C24` 深底 |
| **墨色** | 主文字，最高对比 | 20–25% | `#1A1A1A` / `#F5F0E6` |
| **强调** | 主角 / CTA / 关键数字 | 5–10% | 一个暖色或冷色 |
| **弱化** | 注记 / 分隔 / 次要信息 | 5–10% | 墨色的 40–60% 亮度 |

**60-30-10 原则**：背景 60、墨色 30、强调 10。强调色多了 = 没有强调。

需要更细的系统时，可以扩展成角色（不是颜色数量）：

| 扩展角色 | 用途 | 注意 |
|---|---|---|
| **表面 surface** | 卡片、面板、分区 | 与背景有轻微明度差 |
| **次级文字** | 说明、注记 | 对比略低，但不能读不清 |
| **语义色** | 成功/警告/错误/信息 | 不能只靠颜色，配图标/文字 |
| **禁用/弱化** | 不可用、次要 | 仍要能辨认 |

## 三、对比的六种类型（都服务于层级）

| 类型 | 怎么做 | 用在哪 |
|---|---|---|
| **明度对比** | 深底浅字 / 浅底深字 | 主文字，保证可读 |
| **色相对比** | 冷底 + 暖强调（或反过来） | 让主角跳出来 |
| **饱和度对比** | 大面积低饱和 + 小面积高饱和 | 强调色只在主角上 |
| **面积对比** | 大块安静 + 小块强烈 | 主角占比小但更亮 |
| **冷暖对比** | 背景冷、主体暖 | 产品/人物更突出 |
| **虚实对比** | 背景压暗/去饱和，主体清晰 | 大图压在图上时 |

**同时对比**：同一个颜色放在不同背景上，看起来会不一样。
不要孤立地判断一个颜色“好不好看”，要放在它实际相邻的颜色里看。

**对比不是花哨，是让主角被看见。** 如果每个元素都在对比，等于没有对比。

## 四、配色方案

| 方案 | 做法 | 感觉 | 风险 |
|---|---|---|---|
| **单色** | 一个色相 + 明度/饱和度变化 | 统一、克制、容易高级 | 容易单调；靠明度/材质 |
| **邻近色** | 色轮上相邻 2–3 色 | 和谐、自然、柔和 | 对比弱；需要明度差 |
| **互补色** | 色轮相对两色 | 强对比、抢眼 | 容易刺眼；控制面积 |
| **分裂互补** | 一个主色 + 对面两侧 | 对比但更柔 | 颜色多，容易散 |
| **三角** | 色轮三等分 | 活泼、平衡、强对比 | 难控制；要选主色 |
| **四角** | 两组互补/四等分 | 丰富、复杂 | 容易乱；必须有主导 |

用法：**先定角色（背景/文字/强调），再选方案**。不要先挑六个颜色再想怎么用。

## 五、三个示例配色（不是风格清单）

> 下面是**示例**，不是默认套餐；真正的风格方向由 `design-style` 的轴/参考决定。
> 选它们之前先回 §〇 写 color brief。

| 方向 | 背景 | 墨色 | 强调 | 字体搭配 |
|---|---|---|---|---|
| **编辑感** | `#F7F3EA` 米白 | `#1A1A1A` | 一个暖色（赭石/砖红） | 高对比衬线标题 + 中性黑体正文 |
| **冷科技** | `#0E0C24` 深底 | `#F5F0E6` 浅字 | 冷紫 / 青 | 中性无衬线标题 + 正文 |
| **暖生活** | `#FDF8EF` 奶油 | `#3B2E25` 深棕 | 橙 / 绿 | 高对比衬线标题 + 中性黑体正文 |

⚠️ **具体字体从当前可用字体里选**：中文必须选**有中文字形**的字体；只有拉丁字形的展示体只用于英文短标题，不要拿去排中文，否则中文字形会变成别的字体。

字体最多**两个字族**：一个标题字体 + 一个正文字体。
标题用 600–900 字重，正文 400；**不要正文也用 900**——层级会糊。

## 六、文字压在图上：必须给可读性

> 文字区选在哪（素材安静区、放上还是放下）在构图阶段完成，见 `04-构图推导.md`；
> 这里只处理压暗层与对比度。

- 图上有文字时，先加**压暗层（scrim）**：一个矩形块覆盖文字区，
  填充半透明深色（如 55% 黑）；浅底图用半透明浅色；
- **不要用灰色实块**——灰块会变成"贴纸"，不是压暗；
- 文字与背景的对比度目标 **≥ 4.5:1**（正文）；标题可以略低，但不能糊；
- 压暗层要**只盖文字带**（通常 `.30–.45`），不是盖满全图，更不要 `.60` 把主体一起压掉；
- **优先用渐变**：从深到透明；整块实色会在边缘留一条硬边；
- **深色细节图放在暗背景上会糊在一起**：优先把它移到亮区（窗户 / 浅墙），
  或在图下面垫一个稍大的浅色矩形衬底（米白）当框——阴影只能辅助，不要靠阴影把暗图"抠"出来。

## 七、文字效果：该用就用

标题压在图上时，**白字 + 无处理 = 平**。可用：

- **描边**：深底浅字 / 浅底深字，只给标题；
- **阴影**：小偏移 / 小模糊，只给需要从背景里脱开的字；
- **渐变填充**：大标题用从亮到暗的线性渐变，小字不要；
- **色块 / 纸带**：用矩形色块垫在文字下，比阴影更稳；
- **字重 / 字号 / 字距**：最便宜的层级，先拉这个。

规则：**每个层级最多 1–2 种效果；正文不加；不要全篇描边 + 阴影 + 渐变一起上。**

## 八、把颜色接到层级上

1. **背景**最安静：低饱和、低对比；
2. **墨色**最高对比：正文可读；
3. **强调**只给杠杆点：主角、CTA、关键数字——**不要给每个标题都上强调色**；
4. **弱化**给注记：日期、地点、脚注，别和正文抢；
5. 一套图共享同一个配色：换图不换色，观众才认得出是"一套"。

## 九、白底纪律

- listing 主图：纯白底、无文字（平台硬约束）；
- 通用设计：**不要默认纯白**——米白 / 奶油 / 浅灰都比纯白有温度；
- 纯白只在"产品本身是白底、要极简"时用，而且要用**留白和层级**撑住，不能靠"空"。

## 十、深色模式与可访问性

**深色模式不是反色**：

- 不要纯白字 + 纯黑底；用略灰的白（如 `#E6E6E6`）和深灰（如 `#121212`）；
- 阴影在深色里效果弱，改用表面明度差/边框；
- 语义色要重新调，不要直接复用浅色模式；
- 对比度仍要满足 4.5:1 / 3:1。

**硬指标**：

- 正文对比度 **≥ 4.5:1**；大文本（≥18pt 或 ≥14pt 粗体）**≥ 3:1**；
- 非文本（图标/控件/状态）**≥ 3:1**；
- **不要只靠颜色**传达信息；用图标、文字、图案、下划线辅助；
- 颜色盲：红绿不要作为唯一区分；用明度/形状/文字；
- 文字压图按**最差区域**测对比，不要只测平均。

## 十一、效果系统：不是原罪

> 效果不是装饰，是**材料、光、深度**的视觉语言。
> 空效果才是问题；平是合法选择，但“平”应该是概念，不是不敢用。

### 11.1 效果的目的

| 目的 | 可用手段 | 例子 | 风险 |
|---|---|---|---|
| **分离 / 可读** | 压暗、模糊、底色、描边 | 文字压图 | 压暗过度，吃掉主体 |
| **聚焦** | 阴影、发光、对比、局部模糊 | 主角从背景脱开 | 每个元素都发光 = 没有焦点 |
| **深度** | 投影、遮挡、透视、景深、接触阴影 | 前后层次 | 光源方向不一致 |
| **材质** | 纸张、颗粒、噪点、金属、玻璃、浮雕 | 奢华/手作/印刷感 | 纹理盖过内容 |
| **氛围** | 光晕、漏光、雾气、渐变、暗角 | 夜景/晨光/戏剧性 | 变成滤镜 |
| **运动** | 拖影、方向模糊、重复、节奏 | 速度/动势 | 影响可读性 |
| **品牌记忆** | 固定光/材质/印刷工艺 | 一套图的一致性 | 趋势过时 |

### 11.2 效果预算

| 层级 | 内容 | 用在哪 |
|---|---|---|
| **0** | 纯平 | 极简/瑞士/纯字体，完全成立 |
| **1** | 功能效果 | 压暗、对比、一个接触阴影 |
| **2** | 焦点效果 | 主角的阴影/发光/描边/渐变 |
| **3** | 氛围/材质 | 颗粒、纸感、光晕、印刷错位 |
| **4** | 表现性效果 | 3D、玻璃、故障、拼贴 |

大多数设计在 **1–3 层**；4 层是风格选择，不是默认。
**效果层级必须跟视觉层级一致**：主角可以有焦点效果，正文不该有。

### 11.3 效果家族

- **光**：方向、色温、软硬、接触阴影、轮廓光；
- **表面**：纸、布、金属、玻璃、颗粒、噪点、划痕；
- **印刷**：网点、套印偏移、墨迹、压印、烫金；
- **深度**：投影、内阴影、模糊、景深、雾气、暗角；
- **颜色**：渐变、duotone、调色、叠色、overlay；
- **几何**：3D、玻璃、铬、折射、扭曲；
- **文字**：描边、阴影、渐变字、纹理字、挤压/立体。

### 11.4 一致性

同一套图里，**光的方向、阴影软硬、模糊半径、颗粒尺度、渐变方向**要一致。
效果家族混乱，比不用效果更廉价。

### 11.5 两套 playbook

**A. 无照片 / 纯文字图形**

- 底：纸感、颗粒、墨迹、渐变、光晕、暗角；
- 字：描边、阴影、渐变字、叠印、压印、字面纹理（只给标题）；
- 形：纸片、金属、玻璃、硬边、半调、套印偏移；
- 光：侧光、漏光、投影、接触阴影；
- 印刷：网点、套印错位、裁切边、油墨不均。

规则：**1–2 个效果家族**，正文不加效果，主角可以有一个“主效果”。
纯字体海报可以很平，但「平」应该是概念，不是没敢用。

**B. 有照片**

- **光向**：照片从左上打光，阴影/高光/渐变就不能从右下；
- **色温**：照片冷，图形/文字的效果也要冷；照片暖，不要加冷蓝发光；
- **接触阴影**：让文字/图形“落在”场景里，而不是浮着；
- **景深/模糊**：前景/背景虚化与照片景深一致；
- **调色**：duotone、overlay、grade 用来统一照片与图形；
- **边缘**：贴边、裁切、出血、卡片，决定它是“融合”还是“贴纸”。

规则：**光的契约优先**。照片硬光 → 硬阴影；照片柔光 → 柔阴影。
不要给照片加和它光源矛盾的发光/阴影。

### 11.6 效果的代价

- 可读性/对比度会不会被破坏？
- 印刷/屏幕上会不会失真（渐变带纹、发光溢出、透明叠色）？
- 会不会让画面变脏/变俗/变成滤镜？
- 同套图能不能复现？
- 效果是在**放大**层级/构图，还是在**替代**它？

> 9 个风格的“允许/避免效果”见 `design-style` 的 `style-system.md`；
> 这里只给通用判断，不重复风格表。

## 十二、自检

1. 四个颜色角色齐了吗？强调色是不是只出现在主角/CTA 上？
2. 明度对比够不够？灰度下层级还成立吗？
3. 颜色是不是太多？有没有一个主导色？
4. 文字压图时有没有 scrim？对比度够不够？
5. 字体是不是只有两个字族？正文有没有被标题字重污染？
6. 一套图里，背景/墨色/强调是不是同一套？
7. 深色模式/色盲/弱视下还成立吗？
8. 能说清 color brief 吗？（受众/品类/情绪/对比/媒介）
9. 每个效果都有目的吗？和光向/风格一致吗？
10. 去掉效果会更清楚吗？是 → 去掉；不是 → 保留并说明它做什么。
