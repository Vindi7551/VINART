# 02 · 排版思想

> 读这份的时机：**构图之前**；或画面平、散、视线乱、元素像表格时回看。
> 这些是**启发式**，不是硬规则。先把基础版式做对（对齐、间距、层级），
> 再用它们加分；**一次用一两个就够**，堆砌会变成视觉噪音。
>
> 这份和 `03-杠杆点.md` 是构图的两块输入：这份管阅读路径 / 字体 / 网格 / 间距 / 层级，
> 03 管主角与手段。读完再进 `04-构图推导.md`。

## 一、先想清楚：视线怎么走？

画面上的元素不是平等的——眼睛会**按顺序**扫过它们，顺序由尺寸、位置、对比决定。
动笔前先回答：

- **主流动**：第一眼看什么 → 然后看什么 → 最后看什么？
- **支流**：可以有次要路径，但**支线不能喧宾夺主**——次级元素的对比必须明显低于主级。

常见倾向：拉丁文阅读文化里，读者容易走 **F 型**（横向扫顶部，再向下、再横向）或
**Z 型**（左上 → 右上 → 左下 → 右下）。但这不是普遍规律：中文横排、竖排、RTL
都会改变路径。把 F/Z 当**启发式**，不是定律；先决定你想让视线怎么走，再用位置/对比去引导。

**阅读节奏由间距和位置控制**：间距小 = 读得快；间距大 = 停顿、喘息。
下面的四档间距就是节奏的刻度。

## 二、三个自检问题（写完草图后逐个回答）

1. **视线是怎么划过版面的？**——需要跳转，还是平滑过渡？（两种都可以，但要**有意为之**）
2. **相关元素在视觉上分组了吗？**——同类的靠近、用同档间距，别让相关的东西散开。
3. **每个元素是增加清晰度，还是制造视觉噪音？**——说不清它为什么存在，就删掉它。

## 三、层级：字号用倍数，尺寸用黄金比例

- **相邻层级的字号成倍数**才有和谐感（如 20 / 40 = 1 : 2）；
  零散字号（18 / 26 / 37）会让画面失序。
- 同一份草图里的字号尽量互成倍数：`.06 / .03 / .015` 比 `.055 / .032 / .017` 稳。
- 元素**尺寸**同理：**黄金比例（1 : 1.618）** 是常用的相邻比，不是“美的定律”；
  一块高 0.50，旁边一块 0.31（= 0.50 ÷ 1.618）通常比随手给的 0.4 更顺眼。

字号用**画布宽的比例**表达，不要写死像素：

| 层级 | 字号档 | 字数 | 用在哪 |
|---|---|---|---|
| 标题 | .06–.13（大字报可到 .16） | 3–8 词 | 钩子 |
| 副标题 | .024–.036 | ≤18 词 | 一句解释 |
| 标签 | .015–.020 | 2–4 词/条 | 部位/要素 |
| 注记 | .013–.018 | ≤12 词 | 日期/地点/注脚 |

**3–4 级通常够**。常见字号阶梯比例：1.125（紧凑）、1.25（常用）、1.333（明显）、
1.5（强对比）、1.618（很强）。不要 8 级；也不要所有文字一个字号。

## 四、字体排印：不是选字体

### 4.1 先分清术语

| 术语 | 含义 | 设计意义 |
|---|---|---|
| **基线 baseline** | 字母底部对齐的假想线 | 行距、基线网格的基准 |
| **x 高度 x-height** | 小写字母主体高度 | 影响“看起来多大”、可读性 |
| **大写高度 cap height** | 大写字母高度 | 标题、全大写标签的比例 |
| **升部 ascender** | 向上超出 x 高度的部分（b/d/k/t） | 行距太紧会撞 |
| **降部 descender** | 向下超出基线的部分（g/p/y） | 行距太紧会撞 |
| **开口 aperture** | 字母开口的负空间（C/S/e） | 开口大通常更易读 |
| **字怀 counter** | 字母内部封闭/半封闭空间（o/e/a） | 影响字重与识别 |
| **字偶距 kerning** | 特定字母对之间的间距 | 标志、标题要大调 |
| **字距 tracking** | 整段/整行的字距 | 小字可略松；正文不要过度 |
| **行距 leading** | 行与行的垂直距离（基线到基线） | 正文通常 1.2–1.5；长行需更大 |
| **行宽 measure** | 一行文字的长度/字符数 | 太长难回行，太短断气 |
| **em** | 相对单位；1em = 当前字号 | 适合响应式/相对间距 |

### 4.2 Typeface、Font、Family

- **Typeface（字体设计本身）**：如 Helvetica、思源宋体；
- **Font（字库文件/具体样式）**：如 Helvetica Bold 12pt；
- **Family（字族）**：一组相关字体（Regular / Bold / Italic / Condensed）。

口语常混用；做系统时要分清**家族、字重、宽度、光学尺寸**。中文尤其要确认：
这个字体有没有真正的中文字形、有没有需要的字重，而不是只有拉丁字母。

### 4.3 字体分类（近似，不是铁律）

| 类别 | 特征 | 常见用途 | 风险 |
|---|---|---|---|
| **旧式衬线** | 低对比、斜轴、人文感 | 书籍、编辑、长文 | 小字号可能偏弱 |
| **过渡衬线** | 对比中等、更理性 | 正文、标题 | 气质较中性 |
| **现代衬线 / Didone** | 高对比、细横笔 | 时尚、奢华、标题 | 小字号细笔画易消失 |
| **板衬线 Slab** | 粗厚衬线、低对比 | 海报、标志、粗犷风格 | 长文易累 |
| **格罗特斯克 / 新格罗特斯克无衬线** | 中性、工业化 | UI、品牌、正文 | 容易“没有性格” |
| **人文无衬线** | 人体感、开口大 | 正文、教育、友好品牌 | 气质偏软 |
| **几何无衬线** | 几何圆、构造感 | 科技、现代、标题 | 小字号识别度可能低 |
| **手写 / 书法** | 手写、书法 | 短标签、邀请、装饰 | 长文不可读 |
| **展示体 Display** | 极端比例、强性格 | 标题、海报 | 不适合正文 |
| **等宽 Monospace** | 每个字符等宽 | 代码、表格、技术标签 | 长文节奏单调 |

### 4.4 正文怎么排

**行宽（measure）**

- 拉丁文正文：常见 **45–75 字符/行**（含空格），长文偏 60–70；
- 中文正文：常见 **25–40 字/行**（经验值，按字号/媒介调整）；
- 标题可以更宽/更窄，按构图需要；移动端更窄，但不要窄到每行 10 字。

**行距（leading）**

- 正文常见 **1.2–1.5 倍字号**；长行、小字、中文通常需要更大；
- 中文正文常见 **1.5–1.8 倍字号**（经验值）；
- 行越长，行距通常要越大；行距太紧会上下撞，太松会散。

**字距与字偶距**

- 正文通常 0 或略正；全大写标签可以略松；大标题可以略紧；
- 不要给正文加很紧的字距；
- 标志、标题、大字要手动检查字偶距；正文交给字体默认。

**对齐**

| 对齐 | 适合 | 风险 |
|---|---|---|
| **左对齐 / 右不齐** | 长文、屏幕、编辑正文 | 右边缘不整，但阅读自然 |
| **右对齐** | 数字、价格、日期、短标签 | 长文难读 |
| **居中** | 短标题、邀请、对称构图 | 长文难读；容易呆板 |
| **两端对齐** | 书籍、报纸、正式出版物 | 容易产生“河流”、字距不均 |
| **自由 / 环绕** | 海报、实验排版 | 难控制；容易乱 |

屏幕正文优先左对齐；两端对齐要配合断词/字距调整，否则会出现难看的空隙。

**段落**

- 首行缩进和段间距二选一，不要同时用；
- 避免孤行/孤字（段首/段尾只剩一行/一个字）；
- 标题不要落在页面/栏的底部（孤行标题）；
- 段落之间用间距分组，不要靠空行堆。

**排版灰度（typographic color）**

一段文字的“灰度”由字号、字重、行距、字距、行宽共同决定。好的正文灰度均匀，
不会一块黑一块白；标题和正文的灰度差，就是层级的视觉信号。

### 4.5 字体搭配

1. **角色对比**：标题字体和正文字体要有明确角色差异，不是“两个都好看”；
2. **最多两个字族**：一个标题体 + 一个正文体，通常够；
3. **不要“相似但不同”**：两个都像 Helvetica 但细节不同，会显得脏；
4. **同家族不同字重**是最稳的搭配；
5. **在实际字号/媒介里测试**：小字号看 x 高度、开口、字重；
6. **中文 + 西文**：优先选有中文字形的家族，或中西文搭配；注意基线、字重、字面大小匹配。

### 4.6 中文排版要点

- **四种常用字体**：宋体（阅读/文化/正式）、黑体（现代/屏幕/标题）、
  楷体（手写感/引文/文化）、仿宋（公文/说明）。各有语气，不要混着用。
- **标点**：汉字与标点原则上占 1:1 方框；横排用弯引号，直排用直角引号；
  不同地区（大陆/台港）标点位置与字形标准不同。
- **行首行尾禁则**：句号、逗号、顿号、右引号等不能出现在行首；
  左引号、左括号不能出现在行尾。
- **中西混排**：汉字与西文之间通常加约 1/4 字宽的空隙；西文用比例字体时
  注意基线、字重、字面大小；不要让西文把汉字行距撑开。
- **不要假斜体 / 假粗体**：中文没有真正的斜体传统，算法倾斜会破坏字形；
  粗体要用真实字重。没有粗体时，宁可换字体/加字号，不要用描边假装。
- **字体回退**：缺字会 fallback 到别的字体，字形/字重可能突变；
  出图前要检查生僻字、标点、数字、英文。
- **直排**：从右到左、从上到下；西文/数字有直排、旋转 90°、纵中横排等处理。
- **首行缩进**：中文常见缩进 2 字；也可以段间距，但不要两者同时用。
- **强调**：加粗、着重号、颜色、字号；不要整段加粗/整段变色。

### 4.7 常见排版错误

- 正文太小 / 对比太低；
- 一行太长或太短；
- 行距太紧（尤其长文/中文）；
- 全篇一个字号；
- 标题和正文用同一字重；
- 两个相似字体混用；
- 正文两端对齐出现河流；
- 大量全大写长句；
- 文字压 busy 图，没有安静区/压暗；
- 假粗体/假斜体；
- 孤行/孤字；
- 中文标点出现在行首/行尾。

## 五、网格：结构不是装饰

### 5.1 网格的组成

- **栏（columns）**：内容的主要垂直分区；
- **栏间距（gutters）**：栏与栏之间的空白；
- **页边距（margins）**：内容与画布边缘之间的空白；
- **模块（modules）**：栏 × 行的交叉单元；
- **基线网格（baseline）**：让文字基线对齐；
- **空间区域（zones）**：页眉、主体、侧栏、页脚。

### 5.2 常见网格类型

| 类型 | 结构 | 适合 | 风险 |
|---|---|---|---|
| **单栏** | 一个主栏 | 长文、书籍、报告 | 单调；需要页边注/图版变化 |
| **栏网格** | 2–12 栏 | 编辑、网页、海报 | 栏太多会碎 |
| **模块网格** | 栏 + 行 | 图集、电商、卡片 | 容易变成“表格” |
| **层级网格** | 按重要性分配大小 | 新闻首页、杂志封面 | 规则复杂；需要强层级 |
| **基线网格** | 按基线排列 | 书籍、长文、多栏 | 图片/标题对齐麻烦 |

### 5.3 12 栏、8pt 与响应式

排版时按 12 列 × 12 行思考，元素边缘尽量落在格线上——同类元素天然互相对齐。
12 能被 2 / 3 / 4 / 6 整除，等分好算：

```
占 1/2  → 左 0 / 0.5              宽 0.5
占 1/3  → 左 0 / 0.333 / 0.667    宽 0.333
占 1/4  → 左 0 / 0.25 / 0.5 / 0.75 宽 0.25
```

四条用法：

1. **边缘落在格线上**——左边距统一 `.083`（= 1 格），不要一块写成 `.09`；
2. **一行多个元素用等分**——2 个各 0.5、3 个各 0.333、4 个各 0.25；
3. **垂直方向同理**——区块间距取同一个值；
4. **重要的占多格**——主角占 6–8 格，次要 2–3 格，标注 1 格；
   刻意空出几格不放东西，画面就透气了。

**8pt / 4pt 网格**：数字产品常用 8 或 4 的倍数做间距/尺寸，便于系统化；
但字号不必强行对齐到 8 的倍数，否则会为了网格牺牲排版。

**响应式**：桌面 12 栏 → 平板 8 栏 → 手机 4 栏/单栏；
断点按内容需要，不按设备型号；先决定内容优先级，再决定栏宽/断点。

### 5.4 Swiss Style 的网格观

Swiss Style（国际主义排版）在 1940s–50s 的瑞士发展起来，强调无衬线、非对称、
网格、摄影、客观传达（见 `design-style` 的历史流派）。
它的核心不是“左对齐 + Helvetica”，而是**用系统约束保证清晰与一致**。
网格是手段，不是风格标签；不要为了“瑞士感”把内容硬塞进格子。

### 5.5 为什么较真

设计里最常见的错误不是"明显错位"，而是**近似对齐**——
两个元素差了 `0.03`，看起来就像没对齐，**比明显错开还难看**。

**但也别死守网格**：它是参照。想让画面有张力，可以**故意偏离**——
稍微斜一点、稍微错开一点。**偏离要有意图，不要是随手的偏差。**

### 5.6 打破网格：大部分对齐，一个故意不

- 全部对齐 → 平稳但可能无聊；
- 全部乱来 → 就是乱；
- **大部分元素守格 + 一个明显打破** → 冲击力 ✓

那个打破的元素会自动成为焦点——所以**通常让杠杆点去打破网格**（大标题偏出半格、
大图压过边距、一个色块故意不对齐），**别让次要元素抢这个戏**。

### 5.7 网格检查

1. 页边距是否统一？
2. 栏宽/栏间距是否成系统？
3. 同类元素是否共享对齐线？
4. 文字是否落在基线/栏线上（或有意偏离）？
5. 图片是否按栏宽/模块裁切？
6. 响应式断点是否按内容需要？
7. 破格是否有理由、是否服务主角？

## 六、节奏：间距只用四档，不要做平均

| 档 | 画布比例 | 用在哪 |
|---|---|---|
| `tight` | `.010` | 元素内部：图标与它的文字 |
| `group` | `.022` | 同一组内：三行说明彼此 |
| `block` | `.045` | 组与组之间：标题 ↔ 副标题 |
| `section` | `.085` | 大区块之间：头部区 ↔ 主要内容区 |

三条纪律：

1. 同一层级用同一个值；
2. 不同层级差 **2 倍以上**；
3. **不要把间距做平均**——全篇等距 = 没有分组、没有节奏，读起来像表格。

`tight` / `group` 让视线连读，`block` / `section` 让它停一下。

**落到坐标上的例子**：

- `title` 底边 → `subtitle` 顶边：用 `group` 档（≈ `.022` 画布高）；
- 上一区块 → 下一区块：用 `section` 档（≈ `.085`）；
- 不要把 title 和 subtitle 拉到 `.07`——那不是"紧贴"，是两块互不相干的内容。

## 七、层次感：让相邻元素**稍微重叠**

完全平铺的版式像表格。让相邻元素**边缘稍微压过彼此**（压 2–6% 画布），
画面立刻有前后层次。

做法：两个独立节点 + 位置重叠 + **图层顺序定前后**。

⚠️ 是"**稍微**"——压住对方一个边角，不是大面积盖住。

## 八、张力 / 阻力（有意为之的不舒服）

不是所有"不舒服"都是错的。以下三种是**故意的紧张感**，用一次就够：

- **拥挤**：让一组元素靠得比舒适距离更近，制造密度；
- **突兀**：一个元素明显不遵守其他元素的规则（颜色、大小、方向）；
- **悬空 / 出血**：主体压出画布边缘，制造"没被框住"的张力。

⚠️ 张力必须服务信息：它应该让**主角**更突出，而不是让读者找不到重点。

## 九、留白：不是默认值，是构图结果

- ❌ "干净留白"不是默认审美——它经常是"画面空"的借口；
- ✅ 留白有两种：**隔离**（围住主角，见 03）和**呼吸**（区块之间的 `section` 档）；
- 主体占太小 + 大片空 = 稀疏，不是高级。

## 十、检查顺序

1. 眯眼 / 缩到 20%：第一眼看到的是不是主角？（见 `03-杠杆点.md`）
2. 视线能不能按"主 → 次 → 注记"走完？
3. 间距有没有档差？分组清不清楚？
4. 字号/行宽/行距/对齐是否可读？
5. 网格/对齐是否统一（或有意偏离）？
6. 有没有哪个元素既不加清晰度、也不服务主角？删。
7. 有没有"近似对齐"（差 0.03 那种）？要么对齐，要么明显错开。
