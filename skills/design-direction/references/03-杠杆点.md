# 03 · 杠杆点（视觉层级）

> 读这份的时机：**构图之前**，先定主角；或用户说"画面平、没有重点、不知道看哪"时。
> 一句话：**一个画面只有一个主角。** 其他元素都是为它服务的。
>
> 这份和 `02-排版思想.md` 是构图的两块输入：02 管阅读路径 / 网格 / 间距 / 层级，
> 这份管主角与手段。读完再进 `04-构图推导.md`。

## 一、什么是杠杆点

"杠杆点" = 版面最核心的元素：主体、大标题、让人记住的那个东西。
它是**第一眼**看到的东西，也是读者离开画面后唯一记得的东西。

一套图可以有不同主角（这张是主体、那张是细节），但**一张图里只能有一个**。
如果有两个元素在抢，读者会两个都记不住。

## 二、层级 ≠ 尺寸

> "Large images in prominent locations often rank high... **but they do not
> automatically become the primary focal point**."

大图不等于主角。尺寸只是六个杠杆之一。

**决定层级的六个杠杆**：

| 杠杆 | 怎么起作用 | 草图阶段能落吗 |
|---|---|---|
| **尺寸** | 明显比周围大 | ✅ 尺寸 |
| **对比** | 明暗 / 色彩 / 疏密差异 | ⚠️ 尺寸可以；颜色 / 明度在外观阶段（见 06） |
| **位置** | 放在视线落点（中线、三分线交点） | ✅ 左 / 上位置 |
| **色彩强度** | 饱和度 / 明度 / 冷暖 | ⚠️ 外观阶段 |
| **隔离与装框** | 用留白或外框把它和周围分开 | ✅ 间距 + 矩形 / 椭圆外框 |
| **焦点锐度** | 清晰 vs 模糊 / 细节密度 | ⚠️ 主要靠素材，草图只能靠尺寸与位置 |

**选一两个杠杆就够，不要六个全用。** 全用 = 每个元素都在喊 = 没有主角。

## 三、突出杠杆点的四个手段

| 手段 | 怎么做 | 在草图里 |
|---|---|---|
| **缩放** | 明显比别的元素大（不是大一点） | 把尺寸拉到 1.3–2 倍 |
| **对比** | 别人都小、都暗，它大、它亮 | 尺寸 + 外观颜色（06） |
| **定位** | 放在视线落点：中线、三分线交点、左上/中心 | 调左 / 上位置 |
| **隔离** | **用留白包围它**——它周围空，别的挤 | 用 `section` 档间距围着它 |

**优先用「隔离」和「缩放」**：它们不依赖颜色，草图阶段就能看出来。
「对比」和「色彩强度」要等外观阶段，别在草图阶段假装已经做到了。

## 四、隔离与装框（最容易被忽略的杠杆）

> "Isolating an image within a frame, colored shape, or surrounding whitespace
> separates the image from its surrounding and **draws attention to what is enclosed**."

两种做法：

1. **留白隔离**：主角四周留 `section`（.085）档空白，其他元素挤在 `group`（.022）档；
2. **装框**：给图片 / 图形内容项加一个矩形或椭圆外框，框本身就把注意力圈进去了。
   框不是装饰，是**层级手段**——但一个画面里最多一个强调框，不要每个图都加框。

## 五、眯眼测试（squint test）

把画面缩到 20%（或眯眼看）：

- 还能不能一眼看出主角？
- 主 → 次 → 注记 的顺序还清不清楚？
- 如果所有东西糊成一片，说明层级不够——回 `02-排版思想.md` 调尺寸/间距/分组。

**这是提交前必做的一步**，不用工具，肉眼就能做。

## 六、在草图里怎么检查

对着当前版式或草图的数值问：

1. 谁是主角？把它圈出来（名字写下来）。
2. 它比第二重要的元素大多少？**小于 1.3 倍就不算"明显大"**。
3. 它周围有没有 `section` 档留白？还是和别的元素挤在 `group` 档？
4. 它的位置在不在视线落点？（中线 / 三分线 / 左上）
5. 有没有第二个元素也在用同样的手段抢？（有就撤掉一个）

## 七、反例

- 三条内容一样大、一样间距、一样清晰 → 没有主角；
- 标题很大，但大图也很大，两者在抢；
- 每个元素都加了外框 / 都用了强调色 → 等于没有强调；
- 主角放在右下角，视线先被左上角的小字吸走；
- 用“渐变 / 描边 / 阴影”强化主角可以，但尺寸和位置没让位——效果是放大器，不是层级本身。

## 八、主角检查（提交草图前）

对着**素材**和当前版式回答；有一条不过就改：

1. 主角是谁？写一句「主角是 X，因为 Y」。
2. **主角是主体时**：scrim / 压暗 / 装饰有没有把它压掉？关键部位（材质、标签、结构）还看得见吗？
3. **主角是标题时**：主体还认得出吗？标题压在图上时，有没有把主体切成两半？
4. 文字区在素材的**安静区**吗（暗部 / 天空 / 桌面），还是在主体上？
5. scrim 只盖文字块吗？高度 `.30–.45`？有没有 `.60` 那种把主体一起压掉、还留一条硬边？
6. 缩到 20%：第一眼看到的是主角，还是背景 / scrim 的硬边？

> 这一节就是"构图意图对了但画面平/主体没了"的拦截点。**没读这一节，不要进入落版。**
