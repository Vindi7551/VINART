## 设计风格（方向，不是套餐）

**风格 = 一小组视觉决定的一致性**，不是一套固定参数。

本 skill 只给**倾向、边界、反模式**：
不锁死 hex、不锁死字体、不锁死坐标。
同一个风格，换产品、换内容，应该长得不一样。

### 和其他 skill 的分工

| skill | 管什么 |
|---|---|
| `source-analysis` | 读原始素材/文本：事实、形式、语义、联想、氛围；输出 source brief |
| `design-style` | 气质、色彩倾向、字体性格、密度、材质/光线、装饰系统 |
| `design-direction` | 内容清单、构图推导、层级、间距 |

流程：

```
有原始素材/文本 → source-analysis（source brief）
→ 定风格（本 skill）→ 风格 brief → design-direction 列内容清单 / 推导构图
→ 版式阶段 → 素材 / 外观阶段
```

---

### 第 0 步 · 先定轴，再选参考

- 用户点名风格 → 把名字翻译成 **2–3 个轴**（见 `references/style-system.md`），再读对应风格文件；
- 用户没说 → 根据**主题、受众、使用场景**选 2–3 个轴，**不要默认极简/白底**；
- **最多一个主方向 + 一个 30% 的调味方向**，不要超过两个；
- 轴 + 参考，不是“风格名套餐”；风格必须服务内容：先保证可读、可识别，再谈气质。

> 不要问“你想要什么风格”这种开放题；给方向让用户选。
> 也不要只给一个风格名；给“轴 + 参考 + 一个具体决定”。

### 第 1 步 · 读一个风格文件（参考，不是菜单）

| 文件 | 一句话 | 什么时候读 |
|---|---|---|
| `styles/typographic.md` | 字体排印：字号、网格、字距做主视觉 | 没有照片、展览/演出/编辑/纯文字海报 |
| `styles/editorial.md` | 杂志编辑：大图、强标题、网格、留白 | 内容型、品牌故事、展览/编辑 |
| `styles/minimal.md` | 极简：少元素、大留白、精确 | 高端、科技、极简产品 |
| `styles/swiss.md` | 瑞士网格：客观、系统、非对称 | 信息图、产品说明、机构 |
| `styles/luxury.md` | 奢华：深底/米白、细衬线、金属色 | 美妆、珠宝、高端礼赠 |
| `styles/brutalist.md` | 粗野：超粗字、撞色、硬边、暴露网格 | 街头、音乐、潮流、年轻化 |
| `styles/organic.md` | 自然手作：土色、纹理、柔光、不完美 | 食品、家居、手作、户外 |
| `styles/retro.md` | 复古：年代配色、颗粒、徽章、粗衬线 | 怀旧、食品、活动、联名 |
| `styles/tech.md` | 科技：深底、冷色、网格、等宽字 | 数码、SaaS、未来感 |

读法：先读 `references/style-system.md` 的轴与映射，再打开一个风格文件；
**风格文件是参考锚点，不是选项菜单**。一次只读当前主参考；有调味参考再读第二份。

> 没有照片 / 产品图时，先考虑 `typographic` 或插画 / 几何主视觉；
> 不要为了“有图”硬塞商品照。

### 第 2 步 · 历史流派（只在需要时）

当用户点名 **Bauhaus / Art Deco / Swiss / Constructivist / Memphis / Y2K** 等，
或当代方向需要历史依据时，读：

`references/history.md`

规则：

- **借语法，不借 logo、不借品牌、不借整张构图**；
- 现代 70% + 历史 30%，不要做成年代 cosplay；
- 历史流派只提供“为什么这样排/这样配色”的依据，不提供模板。

### 第 3 步 · 输出 style brief

在推导构图之前，先在对话里写一份 brief：

```
参考：editorial（70%）+ organic（30%）
风格轴：冷 70% + 手作 30%；密度中低；几何为主，一点有机
关键词：克制、纸张感、晨光
色彩：暖白底 / 近黑墨 / 赭石强调 / 灰褐弱化（给角色，不锁死 hex）
字体性格：高对比衬线标题 + 中性黑体正文（具体字体从可用字体里选）
构图：密度中低，留白约 30%，12 栏，文字右下
图像/材质：纪实、自然光、纸张纹理
效果/材质：轻颗粒 + 纸感 + 柔和接触阴影；不要玻璃拟态
装饰：细线 + 小标签，不用卡片阴影
禁止：纯白底、荧光色、居中对称、四种以上颜色
允许偏离：主标题可以故意压出网格半格
```

**brief 是给后续步骤看的约束，不是最终文案。**

### 第 4 步 · 交接

| 要交接的东西 | 交给 |
|---|---|
| 色彩 / 字体 / 密度 / 材质 | style brief |
| 构图关系 / 骨架 | `design-direction` |
| 素材 / 光线 / 场景 | 素材阶段 |
| 效果 / 材质（阴影、颗粒、渐变、玻璃、印刷感） | 外观阶段（按当前阶段能力处理） |
| 装饰 / 旋转 / 透明度 | 外观阶段（按当前阶段能力处理） |

**风格 skill 只输出方向与 brief，不直接改版式。**

### 反模式（出现任意一条就不合格）

- **风格 cosplay**：照抄某个品牌/年代海报的完整构图；
- **只有风格名，没有轴**：说得出“杂志感”，说不出冷/暖、密/疏、几何/有机；
- **一张图三种风格**：editorial + luxury + tech 混在一起；
- **只有配色像**：颜色对了，字体、密度、材质、效果全不对；
- **为了风格牺牲可读性**：小字压在花纹上、OCR 读不出；
- **“高级感 = 全黑 + 金字”**：这是最偷懒的奢华；
- **为了“干净”拒绝所有效果**：平不是错，但“平”应该是概念，不是没敢用；
- **效果堆砌**：每个元素都发光/投影/渐变，等于没有焦点；
- **用风格标签代替设计决策**：说得出“杂志感”，说不出三个具体选择。

### 自检

- 能说出 **2–3 个风格轴**吗？还是只有一个风格名？
- 能说出 **3 个由这个风格决定的具体选择**吗？（颜色/字体/密度/材质/效果/装饰）
- 去掉“风格”这个词，画面还成立吗？
- 风格在**色彩、字体、构图密度、材质、效果**五个维度都成立吗？只成立一个就是贴标签。
- 可读性、层级、主角还在吗？
- 有没有**一个故意偏离**，让画面不像模板？
- 效果/材质是在服务风格，还是在堆砌？
