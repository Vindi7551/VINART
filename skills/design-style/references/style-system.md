# 风格系统：轴、映射与参考

> 读这份的时机：**写 style brief 之前**。
> 风格不是 9 个名字，而是一组轴 + 参考；9 个风格文件是**参考锚点**，不是菜单。

## 一、为什么用轴

- 只用风格名，模型会先选 `editorial` / `luxury`，再硬套颜色和字体，容易变成风格 cosplay；
- 轴把“感觉”翻译成可执行决定：颜色、字体、图像、构图、装饰、效果；
- 一次选 **2–3 个轴**，不要 8 个全选；轴太多 = 没有方向。

## 二、八个轴

| 轴 | 两端 | 要回答什么 | 常见误判 |
|---|---|---|---|
| **温度** | 冷 ↔ 暖 | 画面应该冷静/精密，还是温暖/亲近？ | 把“暖”只理解成橙色 |
| **密度** | 密 ↔ 疏 | 信息密集/热闹，还是留白/安静？ | 把“疏”理解成东西少 |
| **形态** | 几何 ↔ 有机 | 秩序/构造，还是自然/手作？ | 几何 = 只用方块 |
| **时间** | 历史 ↔ 当代 | 借历史语法，还是当代语汇？ | 历史 = 复古滤镜 |
| **音量** | 安静 ↔ 响亮 | 克制/低声，还是冲击/叫卖？ | 响亮 = 高饱和 |
| **质感** | 精致 ↔ 粗粝 | 精细/抛光，还是原始/磨损？ | 粗粝 = 脏 |
| **明度** | 明亮 ↔ 暗沉 | 轻/通透，还是重/戏剧？ | 暗 = 高级 |
| **复杂度** | 克制 ↔ 繁复 | 少元素/强秩序，还是多元素/装饰？ | 繁复 = 堆满 |

## 三、轴 → 视觉决定

| 轴的一端 | 色彩 | 字体 | 图像 | 构图 | 装饰 | 效果 |
|---|---|---|---|---|---|---|
| **冷 / 精密** | 冷色、低饱和、高对比 | 几何无衬线、紧字距 | 硬光、金属/玻璃、微距 | 强网格、非对称 | 细线、刻度、编号 | 冷光、玻璃、轻模糊 |
| **暖 / 手作** | 土色、奶油、低对比 | 人文衬线/圆润无衬线 | 自然光、纸张/布料 | 松网格、轻微错位 | 印章、纸边、手写标签 | 颗粒、纸感、柔光 |
| **密 / 响亮** | 高饱和、撞色、大面积色块 | 超粗、压缩、全大写 | 闪光灯、高对比、拼贴 | 满幅、重叠、出血 | 胶带、编号、粗线 | 硬阴影、半调、套印偏移 |
| **疏 / 安静** | 米白/浅灰、低饱和 | 细字重、宽字距、大字号 | 留白、浅景深、自然光 | 大边距、单焦点 | 一条细线/一个小点 | 极轻的纸感/阴影 |
| **历史 / 编辑** | 米白、墨色、一个低饱和强调 | 高对比衬线 + 中性正文 | 纪实、自然光、纸张 | 12 栏、大图、留白 | 期号、细线、小标签 | 纸感、墨迹、duotone |
| **当代 / 科技** | 深底、冷色、荧光点缀 | 几何无衬线/等宽 | 3D、暗场、冷光边缘 | 模块化、强网格 | 坐标、状态标签、细线 | 冷光、玻璃、微光、模糊 |

> 表是**映射示例**，不是公式。同一个轴可以有不同的颜色/字体实现；
> 关键是这些决定要**互相支持**，而不是各选各的。

## 四、三个 worked example

### 1. 暖 / 手作 / 疏

- 色彩：奶油底、陶土/橄榄强调、低饱和；
- 字体：人文衬线标题 + 圆润无衬线正文；
- 图像：自然光、纸张/布料、手部动作；
- 构图：非对称、边距偏大、留白多；
- 装饰：印章、纸边、手写短标签；
- 效果：细颗粒、纸感、柔光；不要金属高光/霓虹。

### 2. 冷 / 精密 / 密

- 色彩：深海军蓝/近黑底、冷青/电蓝强调、高对比；
- 字体：几何无衬线、紧字距、数字用等宽；
- 图像：硬光、金属/玻璃、微距、暗场；
- 构图：强网格、模块化、非对称；
- 装饰：细线、刻度、坐标、状态标签；
- 效果：冷光、玻璃、轻模糊；不要暖纸感/手绘。

### 3. 历史 / 编辑 / 克制

- 色彩：米白、近黑墨、一个低饱和强调（赭石/酒红）；
- 字体：高对比衬线标题 + 中性黑体正文；
- 图像：纪实、自然光、浅景深；
- 构图：12 栏、大图、标题偏左/偏下；
- 装饰：期号、细线、小号大写标签；
- 效果：纸感、墨迹、duotone、轻颗粒；不要卡片阴影/玻璃拟态。

## 五、怎么用 9 个风格文件

1. **用户点名风格**：把名字翻译成轴，再读对应文件，借 1–2 层（颜色/字体/构图/材质），不照抄整张；
2. **用户没说**：从 brief 选 2–3 个轴，再找最近的参考文件；
3. **最多一个主参考 + 一个 30% 调味**；不要三个风格平摊；
4. 风格文件里的 hex/字体是**示例**，不是必须；具体值按品牌/可用字体/可访问性调整。

## 六、style brief 模板（带轴/效果）

```
风格轴：冷 70% + 手作 30%；密度中低；几何为主，一点有机
参考：editorial（借网格/标题）+ organic（借纸感）
色彩：暖白底 / 近黑墨 / 赭石强调 / 灰褐弱化
字体：高对比衬线标题 + 中性黑体正文（具体字体从可用字体里选）
图像：纪实、自然光、纸张纹理
构图：12 栏、非对称、文字右下
效果/材质：轻颗粒 + 纸感 + 柔和接触阴影；不要玻璃拟态
装饰：细线 + 小标签
禁止：纯白底、荧光色、四种以上颜色
允许偏离：主标题压出网格半格
```

## 七、9 个参考风格的效果倾向

| 参考 | 可以用的效果 | 要避免 |
|---|---|---|
| **editorial** | 纸感、墨迹、duotone、轻颗粒、柔和接触阴影 | 卡片阴影、玻璃拟态、荧光 |
| **minimal** | 一个精确阴影、细线、纸感 | 多层发光、复杂纹理 |
| **luxury** | 金属/烫金/压印、柔光、深色渐变 | 满屏金光、卡通贴纸 |
| **brutalist** | 硬阴影、半调、套印偏移、扫描线 | 柔和阴影、圆角、玻璃拟态 |
| **organic** | 纸张、颗粒、柔光、手作边缘 | 金属高光、霓虹 |
| **retro** | 半调、套印错位、颗粒、褪色 | 现代玻璃、干净渐变 |
| **tech** | 冷光、玻璃、模糊、微光 | 暖纸感、手绘 |
| **swiss** | 几乎不用效果；靠网格/字体/摄影 | 装饰性发光、纹理 |
| **typographic** | 字面纹理、描边、阴影、渐变字、叠印 | 效果叠加过多 |

> 这是**参考**，不是开关列表。效果要服务轴/内容；平也是合法选择。

## 八、风格评估

1. 能说出 2–3 个轴吗？还是只有一个风格名？
2. 颜色/字体/图像/构图/装饰/效果，是否都支持这些轴？
3. 去掉风格名，画面还成立吗？
4. 有辨识度，但不是照抄某个品牌/年代？
5. 可读性、层级、可访问性还在吗？
6. 同套图能延展吗？换比例/换媒介还成立吗？
7. 有没有一个故意偏离，让画面不像模板？
