# 历史流派参照

> 读这份的时机：用户点名某个年代/流派（Bauhaus、Art Deco、Swiss、Constructivist、Memphis、Y2K……），
> 或者当代风格需要历史依据时。
>
> **历史流派不是模板，是语法。**
> 借它的结构、比例、色彩逻辑、排版习惯；**不借**具体 logo、品牌、整张构图。
> 默认比例：**现代 70% + 历史 30%**。超过 50% 就会变成年代 cosplay。

## 一条时间线

| 流派 | 年代 | 可借的视觉语法 | 不要照抄 | 对应当代方向 |
|---|---|---|---|---|
| **Arts & Crafts** | 1880s–1910s | 手作感、自然纹样、材料诚实、装帧 | 繁复花边、复古印刷仿制 | `organic` |
| **Art Nouveau** | 1890–1910 | 有机曲线、鞭形线、植物母题、装饰性边框 | 满屏曲线、过度装饰 | `organic` + `luxury` |
| **Constructivism** | 1910s–20s | 对角线、红/黑、粗无衬线、照片拼贴、强方向 | 政治宣传语态、具体海报构图 | `brutalist` + `swiss` |
| **De Stijl** | 1917–31 | 原色、矩形、非对称平衡、黑线分隔 | 只变成"红黄蓝方块" | `minimal` + `swiss` |
| **Bauhaus** | 1919–33 | 几何、功能主义、无衬线、网格、工艺与工业结合 | 三原色 + 三角圆方 = 表面符号 | `minimal` / `swiss` |
| **Art Deco** | 1920s–30s | 对称、阶梯形、金/黑、几何角饰、奢华材料 | 满屏金色、装饰盖过内容 | `luxury` |
| **Swiss / International** | 1950s–60s | 12 栏网格、无衬线、左对齐、非对称、客观摄影 | 把网格做成"性冷淡模板" | `swiss` / `editorial` |
| **Pop Art** | 1950s–60s | 商业图像、半调网点、高饱和、重复、漫画分格 | 版权图像、廉价复制感 | `retro` + `brutalist` |
| **Psychedelic** | 1960s | 变形字、高饱和渐变、有机形、密集 | 完全放弃可读性 | `retro` + `brutalist` |
| **Postmodern / Memphis** | 1970s–80s | 戏谑、撞色、几何图案、故意不和谐、装饰回归 | 无层级地乱拼 | `brutalist` + `retro` |
| **Grunge** | 1980s–90s | 做旧、颗粒、层叠、手撕边、低保真 | 脏到读不清 | `brutalist` + `retro` |
| **Y2K** | late 90s–2000s | 铬色、渐变、气泡、科技乐观、未来 UI | 过时特效堆砌 | `tech` + `retro` |

## 怎么用：三个例子

### 用户说"要 Bauhaus"

- ❌ 不要：红黄蓝三个方块 + 三角圆方 + 无衬线 = 表面符号；
- ✅ 借：**几何秩序 + 功能主义 + 非对称网格 + 无衬线**；
- 落到当代：`minimal` 或 `swiss` 为主，用**一个**几何元素做强调（一个圆/一条斜线），
  不是把整套几何图形铺满。

### 用户说"要 Art Deco"

- ❌ 不要：黑底 + 满屏金色 + 放射线；
- ✅ 借：**对称、阶梯形、细金线、几何角饰、奢华材料**；
- 落到当代：`luxury` 为主，金色只做 1–2 个点；对称可以，但留白要够。

### 用户说"要 Y2K"

- ❌ 不要：铬字 + 气泡 + 渐变全上，读不清；
- ✅ 借：**科技乐观、铬/金属、渐变、圆润未来感**；
- 落到当代：`tech` + `retro`，只保留一个 Y2K 信号（比如一个铬色标题），
  其余用现代网格托住。

## 纪律

1. **先问"借哪一层"**：色彩？字体？网格？装饰？材质？只借 1–2 层。
2. **不要跨两个年代**：70s 色 + 80s 铬字 + 90s 拼贴 = 时间错乱。
3. **现代结构托底**：历史元素是调味，现代网格/层级/可读性是主菜。
4. **不抄具体作品/品牌/logo**：借语法，不借身份。
5. **可读性优先**：历史风格可以"难读"，但不能"读不出信息"。
