# tech · 科技

**一句话**：冷、精密、系统化；用网格、数据、材质和光建立"未来感"，不是堆霓虹。

**关键词**：冷、精密、网格、数据、暗色、未来感。

## 视觉信号

| 维度 | 倾向 |
|---|---|
| 色彩 | 近黑/深海军蓝 + 冷青/电蓝/酸性绿；高对比；金属灰；避免暖米色 |
| 字体 | 几何无衬线（具体字体从可用字体里选）；标签全大写 + 字距；数字可用等宽/表格数字 |
| 构图 | 强网格、模块化、不对称；细线分隔；数据/编号/刻度 |
| 图像 | 3D 渲染、微距、暗场棚拍、冷光边缘；产品像"装置" |
| 装饰 | 网格线、坐标、刻度、状态标签；不要卡通图标、手绘 |

## 落地

- 暗底优先；文字用冷白，不要纯白刺眼；
- 强调色只给一个信息点（数据/按钮/线）；
- 用细线/网格建立系统感，不要用阴影堆层次；
- 光效（辉光/体积光）交给素材，不要用阴影假装；
- 图位按内容关系安排，像产品系统图。

## 反模式

- 满屏霓虹 + 发光 = 廉价科幻；
- 假 HUD/假 UI 贴满画面；
- 暗底 + 小字低对比，读不清；
- "科技"只有蓝色，没有结构。

## 混搭

- ✅ + `swiss`：网格/客观/数据；
- ✅ + `brutalist`：粗字/高对比；
- ❌ + `organic` / `luxury`（暖调）：气质冲突。

## 参考锚点

数据可视化、 sci-fi UI、产品发布页、工业设计。  
**借系统和光，不抄具体界面。**
