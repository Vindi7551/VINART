# retro · 复古

**一句话**：借用某个年代的颜色、字体和印刷质感；**先选年代，不要混年代**。

**关键词**：年代感、颗粒、徽章、粗衬线/圆体、暖色、印刷感。

## 先选年代

| 年代 | 色彩 | 字体 | 常见元素 |
|---|---|---|---|
| 50s | 奶油、薄荷、珊瑚红 | 手写/粗衬线 | 星芒、圆形徽章、斜排字 |
| 60s | 芥末黄、橙、橄榄绿 | 圆体/迷幻 | 气泡字、放射线、有机形 |
| 70s | 焦橙、棕、牛油果绿 | 粗衬线/圆体 | 条纹、太阳、大地色 |
| 80s | 霓虹粉/青/紫、黑 | 几何无衬线/斜体 | 网格、铬色、几何块 |
| 90s | 青绿/紫、灰 | 压缩无衬线/等宽 | 拼贴、颗粒、低保真 |

## 视觉信号

- **色彩**：按年代选 3–4 个色，整体偏暖或偏霓虹；允许高饱和；
- **字体**：粗衬线/圆体/压缩体；标题可以大，标签用全大写；
- **构图**：徽章、边框、放射线、斜排；对称或密集；
- **图像**：胶片颗粒、暖色偏、印刷网点；产品放在年代场景里；
- **装饰**：星芒、缎带、邮票、贴纸；但不要堆满。

## 落地

- 先定年代，再选 3 个视觉信号（颜色/字体/一个装饰），不要全上；
- 颗粒/半调/印刷错位交给生图，不要用 CSS 噪点硬凑；
- 标题可以斜/压边（用 `patch_doc rotate` 对 image/svg/shape，文字旋转暂不支持）；
- 图位可按内容选 `diptych` / `editorial-grid` 等，像老杂志/老海报。

## 反模式

- 混年代（70s 色 + 80s 铬字 + 90s 拼贴）；
- 只加"复古滤镜"，字体/构图还是现代；
- 徽章/星芒太多，变成贴纸墙；
- 手写体整段用，读不清。

## 混搭

- ✅ + `organic`（70s）、+ `brutalist`（90s zine）；
- ❌ + `minimal` / `tech`：会抵消年代感。

## 参考锚点

Mid-century 海报、70s 食品包装、80s 唱片、90s 杂志。  
**借年代语法，不抄具体作品/品牌。**
