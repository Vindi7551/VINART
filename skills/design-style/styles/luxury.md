# luxury · 奢华

**一句话**：贵不是"金色 + 黑色"，而是**低饱和、大留白、细字和克制的金属点缀**。

**关键词**：低饱和、深底/米白、细衬线、金属色、克制、留白。

## 视觉信号

| 维度 | 倾向 |
|---|---|
| 色彩 | 近黑/深绿/酒红 或 米白/奶油；金属色（香槟金/黄铜）只做**小面积**点缀；整体低饱和 |
| 字体 | 高对比细衬线（`Noto Serif SC` 400/700）；字距略松；小号大写标签；正文小、轻 |
| 构图 | 大留白；主体居中或偏一侧；元素少；对称也可以，但要精确 |
| 图像 | 棚拍光、深色背景、材质特写（金属/玻璃/丝绸）；接触阴影交给生图，不用 CSS 阴影 |
| 装饰 | 细金线、细边框、monogram；不要卡通风、贴纸、发光 |

## 落地

- 金色只给 1–2 个点：logo、细线、一个标签；
- 标题不要又大又粗；用**细字 + 大字号 + 字距**显贵；
- 深底时，正文用米白而不是纯白；对比要柔和但不糊；
- 图位可按内容选 `bleed-inset` / `three-up` 等，细节图承担材质证明。

## 反模式

- 全屏黑 + 满屏金字 = 土豪金；
- 金色用在正文/大段文字上；
- 装饰比产品多；
- 小字压在暗纹上，读不清。

## 混搭

- ✅ + `editorial`：用杂志式大图/标题压住奢华；
- ✅ + `art-deco`（历史）：几何金线、对称；
- ❌ + `brutalist` / `tech`：会破坏克制。

## 参考锚点

高端美妆/珠宝/时装广告、Art Deco 海报、酒店品牌。  
**借光和留白，不抄品牌。**
