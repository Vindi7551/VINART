# editorial · 杂志编辑

**一句话**：像一本好杂志的跨页——内容优先、层级清楚、留白是编排出来的，不是空出来的。

**关键词**：编辑感、克制、大图、强标题、网格、细线、纸张感。

## 视觉信号

| 维度 | 倾向 |
|---|---|
| 色彩 | 暖白/米白底 + 近黑墨色 + **一个**低饱和强调色（赭石/酒红/墨绿）；避免纯白和荧光色 |
| 字体 | 高对比衬线标题（`Noto Serif SC` 700）+ 中性黑体正文（`Noto Sans SC` 400）；小标签用大写 + 字距 |
| 构图 | 12 栏网格、非对称；主图 50–65%；文字块偏下/偏左；页边距 6–8%；大量**有意图的**留白 |
| 图像 | 纪实/自然光/浅景深；像报道摄影，不像电商白底图 |
| 装饰 | 细线、期号、栏目名、小号大写标签；**不要**卡片阴影、圆角贴纸、满屏框 |

## 落地

- 背景用 `canvas.background`，不要铺满 `shape`；
- 标题与正文拉开字号档差（约 2.5–3 倍），副标与标题用 `group` 档间距；
- 图槽位可按内容选 `triptych` / `full-bleed-inset` 等；文字放素材安静区；
- 压暗用渐变 scrim，只盖文字带；
- 装饰线用极扁 `rect`，不要用阴影假装层次。

## 反模式

- 大白底 + 几行字 + 一张产品图 = 电商模板，不是 editorial；
- 标题比主图还抢，但内容没有层级；
- 每个元素都加细框/引线，变成"信息图"；
- 字号只有两档，读起来没有节奏。

## 混搭

- ✅ + `organic`：纸张纹理、暖光、手作感；
- ✅ + `brutalist`：只让主标题粗野一次；
- ❌ + `tech`：冷光/霓虹会破坏纸张感。

## 参考锚点

杂志跨页、展览海报、纪实摄影集、Swiss 编辑设计。  
**借编排逻辑，不抄具体版式/品牌。**
