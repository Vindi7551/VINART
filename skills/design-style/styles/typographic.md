# typographic

**一句话**：字体就是主视觉——用字号、字重、字距、网格和色块撑画面，不靠照片。

**关键词**：字体排印、字号对比、网格、字距、单色 / 双色、印刷感。

## 视觉语法

| 维度 | 规则 |
|---|---|
| 色彩 | 黑 / 白 / 米白 + 一个强调色；或双色套印；不要多彩渐变 |
| 构图 | 严格网格 / 基线；标题可以出血、压边；标题与正文 3–5 倍字号差 |
| 图像 | 0 图；要质感用纸张、颗粒、套印错位，不要产品照 |
| 字体 | 一个 display + 一个 text；标题 700–900，正文 400；字距松/紧要成体系 |
| 装饰 | 细线、编号、色块、几何；不要投影 / 发光 |
| 层级 | 标题 > 副标 > 正文 > 注记；靠字号和留白，不靠颜色堆 |

## 适合

展览 / 演出海报、书籍封面、编辑跨页、品牌宣言、纯文字社媒图。

## 反模式

- 把所有字都放大 → 没有层级；
- 标题和正文都用 900 → 糊；
- 用照片当背景来“救”排版 → 又回到图片海报；
- 全篇一个字号 / 一种字距 → 平。
