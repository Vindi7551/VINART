# organic · 自然手作

**一句话**：像手作/自然材料——暖、软、有一点不完美；不是"小清新模板"。

**关键词**：暖、土色、纹理、柔光、手作、不完美。

## 视觉信号

| 维度 | 倾向 |
|---|---|
| 色彩 | 奶油/米白/沙色/橄榄/陶土/苔绿；低饱和、暖调；避免纯白和荧光 |
| 字体 | 人文衬线（`Noto Serif SC`）或圆润无衬线（`Noto Sans SC`）；正文行距松；手写体只给短标签 |
| 构图 | 非对称；边距不完全平均；允许轻微错位；留白多但有"呼吸感" |
| 图像 | 自然光、真实材质（纸/木/布/陶）、接触阴影；生活场景 |
| 装饰 | 植物线稿、印章、纸边、胶带感；不要金属高光、玻璃拟态 |

## 落地

- 底色不要纯白，用米白/奶油；
- 纹理/纸感交给生图或 `fill` 纹理（如果可用），不要用噪点 CSS 硬凑；
- 标题可以略大，但不要压得太紧；行距放宽；
- 图位可按内容选 `bleed-inset` / `three-up` 等，细节图拍材质；
- 允许一个"不完美"：轻微错位、手写标签、歪一点点的线。

## 反模式

- 粉色 + 圆角 + 叶子 = 小清新模板；
- 纹理盖过内容；
- 低对比导致读不清；
- 所有元素都"软"，没有焦点。

## 混搭

- ✅ + `editorial`：手作质感 + 杂志结构；
- ✅ + `retro`（70s）：土色、颗粒；
- ❌ + `tech`：冷光/霓虹冲突。
