# minimal · 极简

**一句话**：不是"东西少"，而是**只留下必要的，并用比例和留白制造张力**。

**关键词**：留白、少量元素、精确、中性、安静。

## 视觉信号

| 维度 | 倾向 |
|---|---|
| 色彩 | 米白/浅灰/近黑 + 一个低饱和强调色；避免渐变堆叠、荧光色 |
| 字体 | 中性无衬线或细衬线（具体字体从可用字体里选）；字号档少而准；字距略松 |
| 构图 | 1–2 个视觉单位；大边距；强对齐；一个焦点；留白占 40–60% |
| 图像 | 产品/主体干净、背景简单；靠光形和材质，不靠装饰 |
| 装饰 | 最多一条细线、一个圆点；没有就别加 |

## 落地

- 先删：说不清作用的元素直接去掉；
- 主标题可以很大，但正文要小、要少；
- 用 `section` 档留白包围主角，不要平均分布；
- 如果要"空"，主体必须够大或位置够准，否则就是"空"不是"简"。

## 反模式

- 主体太小 + 四周大片空 = 空，不是极简；
- 为了"简"把字缩到读不清；
- 全居中 + 三个元素，像 PPT 封面；
- 用极简当偷懒，不做层级。

## 混搭

- ✅ + `luxury`：深底 + 细字，安静地贵；
- ✅ + `editorial`：把极简当留白纪律，不是当风格；
- ❌ + `brutalist` / 高饱和装饰：会互相抵消。

## 参考锚点

现代主义海报、日式留白、高端产品页。  
**借比例和空间，不抄具体品牌。**
