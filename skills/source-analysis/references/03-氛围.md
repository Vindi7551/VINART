# 03 · 氛围

> 读这份的时机：已经知道素材里有什么，但还说不清“它应该让人感觉到什么”时。
> 氛围不是滤镜，也不是一个形容词；它是一组**被感受到的空间性质**。

## 一、氛围是关系，不是标签

Böhme 的氛围美学把氛围理解为：介于物与感知者之间的、被感受到的空间性质。
它不是纯主观的“我觉得”，也不是物体自带的“属性”，而是**物、环境、感知者共同产生的**。

对平面设计，这意味着：

- 氛围不是“加一层颗粒/模糊”；
- 氛围是光、色、材质、密度、时间、人的距离**共同一致**的结果；
- 同一个素材，换一种光/材质/密度，氛围就变了；
- 氛围不是“风格名”，风格是表达方式，氛围是**被感受到的质量**。

## 二、源氛围 / 目标氛围 / delta

不要直接写“我要高级感”。先分三件事：

| 层 | 问题 | 例子（旧照片） |
|---|---|---|
| **源氛围** | 素材本身已经有什么感觉？ | 暖、褪色、室内、安静、旧 |
| **目标氛围** | 这次设计想让人感到什么？ | 温暖但不安、被自然接管、亲密、时间感 |
| **delta** | 从源到目标，具体加/减什么？ | 保留暖光/纸感；加潮湿的绿、藤蔓的有机线、较硬的裂纹；去掉均匀 sepia |

**delta 才是设计动作。** 没有 delta，就只是在复制素材本来的感觉。

## 三、八个氛围轴

| 轴 | 两端 | 要问什么 | 物理转译 |
|---|---|---|---|
| **温度** | 暖 ↔ 冷 | 亲近/包围，还是冷静/距离？ | 色温、光色、材质 |
| **光** | 柔 ↔ 硬 | 被包裹，还是被审视？ | 阴影软硬、方向、对比 |
| **密度** | 疏 ↔ 密 | 呼吸，还是压迫？ | 留白、重叠、信息量 |
| **材质** | 光滑 ↔ 粗糙 | 精致，还是手作/风化？ | 纸、布、金属、玻璃、颗粒 |
| **时间** | 新 ↔ 旧 | 当下，还是记忆/衰败？ | 褪色、划痕、字体年代、修补 |
| **人的距离** | 亲密 ↔ 疏离 | 独处、亲密，还是被观看？ | 取景、尺度、遮挡、视线 |
| **动静** | 静 ↔ 生长/运动 | 停住，还是正在发生？ | 对角线、重复、模糊、方向 |
| **自然/人工** | 有机 ↔ 几何 | 野生，还是构造？ | 曲线、网格、材料、边缘 |

不用每个轴都填。选 3–4 个真正决定这张图的轴，其余留空。

## 四、形容词 → 物理事实

| 形容词 | 不要只写 | 要能说出来 |
|---|---|---|
| **温暖** | 加橙 | 色温偏暖、低对比、柔光、纸/布材质 |
| **冷冽** | 加蓝 | 冷白、硬光、高对比、金属/玻璃 |
| **安静** | 留白多 | 大边距、低饱和、少元素、柔边 |
| **压迫** | 东西多 | 满幅、近距离裁切、低天花/高墙、密排 |
| **怀旧** | sepia | 褪色、纸边、折痕、旧字体、低饱和暖灰 |
| **野性** | 绿色 | 有机曲线、越界、粗糙边缘、不规则重复 |
| **精致** | 细线 | 小字号、宽字距、精准对齐、光滑材质 |
| **潮湿** | 蓝色 | 低对比、冷绿、柔边、霉斑/水痕、重阴影 |

说不清物理事实的形容词，不是 brief，是口号。

## 五、氛围要一致，不要“滤镜”

同一张图里，如果：

- 光从左上，阴影却向右下；
- 颜色很暖，材质却是冷金属；
- 字体很古典，效果却是霓虹；
- 画面说“安静”，却每个元素都在发光；

那氛围就散了。**一致性 > 强度**。

检查：把画面里最亮的三个东西、最暗的三个东西、最粗糙的三个东西列出来，
它们是否支持同一个氛围？

## 六、例子：旧照片的氛围 brief

```
源氛围：暖、褪色、室内、安静、旧
目标氛围：温暖但不安、被自然接管、亲密、时间感
delta：保留暖光/纸感；加潮湿的绿、藤蔓的有机线、较硬的裂纹；去掉均匀 sepia

温度：暖，但局部冷绿
光：侧逆光，柔中带硬（柔光 + 硬裂纹）
密度：中低，局部被藤蔓压密
材质：纸纤维、灰尘、潮气、干裂
时间：旧，但“还在生长”，不是封存
人的距离：亲密/私密，像翻开一本旧相册
动静：表面静，下面在生长
自然/人工：有机压过几何

物理转译：
- 色：赭石、橄榄绿、暖灰，低饱和
- 光：低对比暖调 + 局部硬边阴影
- 材质：纸纹、颗粒、划痕、霉斑
- 构图：越界、覆盖、从边缘长入
- 字体：旧衬线/手写只做小面积，正文干净
- 效果：轻颗粒 + 纸感 + 柔边；不要全图 sepia
```

## 七、氛围的测试

1. 能用 3–4 个轴说清吗？还是只有一个形容词？
2. 每个轴都有物理转译吗？
3. 光和材质是否支持同一个方向？
4. 去掉颜色/效果，氛围还成立吗？
5. 换成目标受众，氛围会被误读吗？
6. 它是在复制素材的旧氛围，还是做出了 delta？
7. 氛围有没有伤到可读性/层级/可访问性？

## 八、反模式

- **氛围 = 滤镜**：加颗粒/模糊/暗角就以为有氛围；
- **氛围 = 一个词**：“高级/电影感/氛围感”没有物理事实；
- **氛围 = 风格名**：用一个风格标签代替被感受到的质量；
- **氛围不一致**：暖光 + 冷金属 + 霓虹字；
- **氛围盖过内容**：为了感觉，牺牲可读性；
- **复制源氛围**：没有 delta，设计只是素材的复印件；
- **文化误读**：拿不熟悉的符号当“东方/复古/神圣”。
