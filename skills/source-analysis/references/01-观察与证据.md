# 01 · 观察与证据

> 读这份的时机：拿到素材，还没想清楚“它是什么/它哪里特别”时。
> 目标不是写一篇描述，而是建立**可被指认的证据**：每个判断都能回到一个具体的画面/文字细节。

## 一、先分开四种句子

| 类型 | 长什么样 | 例子 |
|---|---|---|
| **观察** | 可以指给另一个人看 | “照片右下角有一道折痕，穿过桌布。” |
| **推断** | 由观察推出，可能错 | “这张照片被反复折叠、携带过。” |
| **联想** | 个人/文化的连接 | “折痕像一条干涸的河。” |
| **决策** | 设计上怎么用 | “让折痕成为标题的分割线。” |

写作时尽量标注类型。最危险的是把**联想**写成**观察**：
“照片里有一条河”不是观察，是联想；“有一道折痕”才是观察。

## 二、字面描述：先写三句笨的

在解释之前，先写：

1. 画面里有哪些人/物/地点？
2. 它们在做什么？谁在看谁？
3. 光从哪来？什么材质？什么颜色？画面边缘有什么？

如果三句写不出来，说明还没看清，不要急着上意义。

## 三、形式透镜（不用全用，卡住时拿来问）

| 透镜 | 看什么 | 可能的设计线索 |
|---|---|---|
| **框与裁切** | 满/空、中心/边缘、出血/留白、谁被切掉 | 结构、张力、主角 |
| **光** | 方向、软硬、冷暧、自然/人工、明暗对比 | 氛围、深度、焦点 |
| **色** | 色相、明度、饱和、面积、冷暖 | 情绪、层级、系列一致性 |
| **材质** | 纸/布/金属/玻璃/皮肤/灰尘/划痕 | 触感、年代、效果 |
| **身体/动作** | 手势、姿态、视线、距离 | 亲近/疏离、叙事 |
| **场景/道具** | 室内/室外、家具、植物、物件 | 语境、隐喻、可借符号 |
| **镜头/视角** | 俯/仰/平、远/近、广角/长焦 | 权力关系、代入感 |
| **字/版式** | 衬线/无衬线、字重、字距、对齐、年代 | 语气、时代、层级 |
| **时间痕迹** | 褪色、裂纹、折痕、污渍、修补 | 真实感、故事、材质 |
| **缺席** | 没有人、没有天空、没有品牌、没有动作 | 留白、悬念、反预期 |

## 四、不同素材，先看什么

| 素材 | 先看 | 别假设 |
|---|---|---|
| **照片** | 光、构图、视线、道具、年代、损坏 | 别假设“旧=怀旧”；旧也可能是压迫/贫困/劳动 |
| **物件** | 材质、磨损、修补、使用痕迹、尺寸 | 别假设“老物件=温暖”；它也可能沉重 |
| **文字** | 谁在说、对谁说、事实/主张、语气、矛盾 | 别把营销话术当事实 |
| **标志/品牌** | 形状、颜色、字体、历史、使用场景 | 别只看 logo，忽略它出现的语境 |
| **参考图** | 借的是结构/颜色/字体/材质哪一层 | 别把“像”当“适合” |

## 五、来源与限制

- 这是谁的素材？原始/二手/翻拍？
- 什么年代？什么地区？什么用途？
- 有没有必须保留的文字/标志/人物？
- 有没有不能改/不能用的部分？
- 素材是否足够支撑一个判断？不够就标“未知”，不要编。

> 来源会改变意义：家庭相册里的照片、档案里的照片、广告里的照片，即使画面一样，
> 它们“是什么”也不同。

## 六、找三个“入口”

不用分析所有细节。先找：

1. **重复**：反复出现的形状/颜色/词/动作；
2. **异常**：不属于这个画面的东西；
3. **缺席**：应该有却没有的东西。

这三样通常比“整体感觉”更能生成概念。

## 七、证据卡

每写一条重要判断，填一张小卡：

```
观察：
推断：
证据（画面/文字里的具体位置）：
反证（什么会让我改变判断）：
```

如果“证据”一栏写不出来，这条判断就还只是感觉。

## 八、常见错误

- 用形容词代替观察：“很复古”“很有故事”；
- 把文化典故当成人人都懂的；
- 只读主体，不读边缘/背景/道具；
- 只读画面，不读文字/来源/用途；
- 过度解释：每个细节都要赋予意义，最后没有重点；
- 忽略缺席：没拍到的东西，可能才是问题。
