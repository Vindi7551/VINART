# declarative —— 声明式渲染器（② 矢量 → HTML）

**职责**：把**版式文档**（`design-sketch.json` + `design-appearance.json`）编译成一份
**自包含 HTML**（图用 `{{占位符}}` 待替换）。**纯函数**：确定性、可复现、**零模型调用**。

**契约真源在 `src/document/`**——本目录只**消费**它，`import type` 契约，契约不知道本目录存在。

| 文件 | 是什么 |
|---|---|
| `render.ts` | **渲染器（成品）**：`renderDesign(spec, {mode:'final'})` |
| `sketch.ts` | **渲染器（草图）**：`renderDesign(spec, {mode:'sketch'})` |
| `shared.ts` | **共享几何**：`layerBox` / `shapeCss` / `transformCss` / `wrap` / `assetKey` —— 两套渲染共用 |
| `render-style.ts` | **渲染参数**：配色与字体的**具体值**（可换的皮；权威定义在 `designassets/`） |

> **两套渲染共用 `shared.ts`**，所以同一份 spec 的**草图和成品的区域位置天然一致**。

## 一、两种模式

| | **成品**（`render.ts`） | **草图**（`sketch.ts`） |
|---|---|---|
| 画什么 | 照片 + 文字 + 颜色 | **只有图位框、灰条、形状块** |
| 用不用素材 | 用（`{{占位符}}`） | **不用**（所以素材没生成也能出图） |
| 用途 | 交付 | 给人审版式 / 喂生图模型当构图控制 |

### 草图是什么、不是什么

> ⚠️ **草图不是最终成品的预览，是「版式蓝图」。**

它不含任何具体图片，只描述"哪里有一块什么"——所以它能在素材还没生成时先出图
（零成本、3 秒）。用途有两个：**给人审版式**，以及**喂给生图模型当构图控制**
（实测模型真的认，连"圆形细节区"这种几何语义都能传达）。

---

## 二、草图的视觉语言（**唯一权威**）

草图是**给人审、给模型读**的蓝图，图形语言是规范过的，**不要随意改**：

| 元素 | 画法 | CSS |
|---|---|---|
| **文字** | 灰条（**高度 = 字号**，宽度 = 块宽）| `.sbar` |
| **图位** | **虚线框** | `.sbox` |
| **已定下来的面**（形状块）| **实心浅色块** | `.sfill` |
| **辅助网格** | **12 等分 + 中心十字**，画在最底层 | `.sgrid` / `.sgrid-axis` |

**三条容易搞错的**：

1. **虚线框是「图位」的专属标记** —— 形状块改用实心块。
   早先两者都画虚线框，读图时分不清"这里要放照片"还是"这里是个块"。
2. **灰条长度 ≠ 字号** —— 长度是**块宽**（版式给定的），**高度**才反映字号。
   VLM 验收时反复误读这一点，已在提示词里校准。
3. **辅助网格是参照，不是骨架** —— 12 × 12 是为了两件事：
   **读数方便**（整数百分比），以及**等分方便**（12 能被 2 / 3 / 4 / 6 整除）。
   元素可以贴着格线排，也可以**故意偏离**来制造张力——
   **校验器不会因为"没对齐网格"报任何错。**

> 网格**不进数据**：它只是画在草图上给人（和 VLM）读数的辅助线。

> ⚠️ **灰条必须居中于盒子**，不能左对齐。左对齐 + 90% 宽会让视觉中心偏左
> `5% × 块宽`，于是 ① VLM 报"文字没居中"（假问题）② **模型会去迎合它，把本来
> 正确的版式改歪**（实测 parfum-noir 那次，文字被从中心 0.50 挪到 0.53）。

## 三、实现要点（都在代码注释里有出处）

| 点 | 说明 |
|---|---|
| **DOM 顺序 = 叠放顺序** | 没有 z-index、没有按 y 排序。`render.ts` 同步 `map` 按 `spec.layers` 顺序拼接，并有**顺序守卫**断言 DOM 里 `data-layer` 出现顺序与数组一致 |
| **每个节点 → 带 `data-layer` 的容器** | 「DOM → 分层 canvas」的前提（见 `document/README.md` 规则 2） |
| **`.dl { isolation:isolate }`** | 不是装饰，是必需：容器若不创建层叠上下文，**内部 `z-index` 会逃出来跟兄弟节点比较**（`scripts/_probe-zindex.ts` 实测） |
| **文字一律 `nowrap`** | 装不下靠**实测两遍算 `fits` 系数**缩字号——折行会撑破版式，比字号小一点糟得多 |
| **占位符用 `assetKey()`** | `scene-prep.png` → `{{SCENE_PREP_PNG}}`；**生成与收集必须用同一个函数**（早先两边各写各的，占位符永远替换不上，渲出断图空壳） |
| **形状填充加在容器自身** | `border-radius` 只裁自身背景、**不裁子元素**——往里铺 div 会让 `ellipse`/`arch` 在草图上仍是方框 |
| **图层隔离截图** | `blink-renderer` 的 `injectCss` + `selector`：先 `*{visibility:hidden}` 再只显示目标层。**不做隔离直接截，截到的是"那片画面"** |

> ⚠️ **SVG 素材暂不支持**：`compose/emit-html.ts` 的 `MIME` 表**没有 `svg`** →
> `.svg` 素材会抛「不支持的图片类型」。`designassets/elements/icons/` 的 14 个图标因此用不了。
> 见 `docs/HYBRID-RENDERING.md` §8。
