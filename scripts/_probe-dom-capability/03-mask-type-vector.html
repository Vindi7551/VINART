能力账本 03 · 蒙版 · 文字 · 矢量

对照 Photoshop 的四种蒙版、字符面板与路径工具。
图层蒙版（渐变淡出）✅ 直接做
mask-image + 渐变 —— 即 PS 的图层蒙版（灰度控制显隐）
形状蒙版（圆形）✅ 直接做
mask-image: radial-gradient 或 SVG mask/clipPath
剪贴蒙版（矢量轮廓）✅ 直接做
SVG clipPath 任意多边形 / 路径 —— 即 PS 的矢量蒙版
文字多色 runs✅ 直接做
Multicolor Runs
每个片段一个 <span> —— 任意片段可有自己的颜色 / 字号 / 字重 / 字体（PS 的字符面板等效）
沿路径文字✅ 直接做
SVG <textPath> —— CSS 无沿路径排字能力，故走内联 SVG
文字描边✅ 直接做
OUTLINE
-webkit-text-stroke（描边字）
渐变 / 纹理文字✅ 直接做
GRADIENT
background-clip:text —— 文字当蒙版填任意渐变/图片
任意矢量路径✅ 直接做
SVG <path d> —— 任意曲线；锚点即"形状点"（数据问题，不是渲染问题）
变换 旋转 / 斜切✅ 直接做
CSS transform（Vinart 契约已有 rotate/skewX）；透视/变形见第 4 页
