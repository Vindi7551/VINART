混合探针 · isolation:isolate 会不会挡住 mix-blend-mode？

结构完全一致：底层渐变 + 中层橙块 + 上层「光栅图层」（真 RGBA 笔刷 PNG）。 唯一变量是容器上的 isolation 与光栅层的 mix-blend-mode。 若 A 与 B 视觉一致 ⇒ isolation 不挡混合；若 A 明显不同（光栅层"浮"在上面）⇒ 挡住。
A · 现状：每层 isolation:isolate ＋ 光栅层 multiply
这就是 Vinart 现在的写法（`render.ts` 的 .dl{isolation:isolate}）。
B · 对照：每层 isolation:auto ＋ 光栅层 multiply
与 A 唯一差别：把 isolation 去掉。
C · 对照：光栅层不做混合（普通叠加）
基准：笔画"浮"在画面上的样子（无混合）。
