能力账本 01 · 图层与合成

对照 Photoshop 图层样式 / 混合模式。判定：✅ 可直接做 · ⚙️ 需近似生成 · ❌ 需光栅。
投影 Drop Shadow✅ 直接做
box-shadow / filter:drop-shadow（后者跟随轮廓，等效 PS 投影）
内阴影 Inner Shadow✅ 直接做
box-shadow: inset …
外发光 Outer Glow✅ 直接做
box-shadow 无偏移 + 色 + 扩散；文字用 text-shadow
内发光 Inner Glow✅ 直接做
box-shadow: inset 0 0 …
描边 Stroke✅ 直接做
outline（向内 outline-offset:-w）或 border
渐变叠加 Gradient Overlay✅ 直接做
linear-gradient / radial-gradient
图案叠加 Pattern Overlay✅ 直接做
repeating-linear-gradient / background-image（图案可来自 SVG/PNG）
混合模式 Blend Modes✅ 部分
CSS mix-blend-mode 支持 16 / 27 种；缺 subtract/divide 等 → 全量需 canvas/WebGPU
斜面和浮雕 Bevel & Emboss⚙️ 需近似
多层 inset 阴影可近似；真正的光照模型（等高线/角度）需 SVG 光照滤镜或自算
