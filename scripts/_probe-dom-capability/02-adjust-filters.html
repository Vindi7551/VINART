能力账本 02 · 调色与滤镜算子

对照 Photoshop 调整层 / 滤镜。全部作用于同一张真实照片（test_product/goose/source.jpg）。
CSS filter 全套✅ 直接做
原图 / 灰度 / 棕褐 / 色相旋转 —— blur brightness contrast saturate hue-rotate grayscale sepia invert drop-shadow，全部原生+GPU
曲线 Curves✅ 直接做
SVG feComponentTransfer 的 type="table" —— 每个通道一条映射曲线，即 PS 的曲线/色阶
通道混合 / 色相✅ 直接做
feColorMatrix type="matrix" —— 通道互换/加权，即 PS 通道混合器
形态学 膨胀/腐蚀✅ 直接做
feMorphology operator="dilate|erode" —— 加粗/瘦身，可做描边外扩
噪声 / 颗粒✅ 直接做
feTurbulence + feBlend —— 即 PS 的「颗粒 / 添加杂色」
光照效果 Lighting✅ 直接做
feSpecularLighting + fePointLight —— 即 PS 的「光照效果」
锐化 Convolution✅ 直接做
feConvolveMatrix —— 任意卷积核，即 USM 锐化 / 自定义算子
位移扭曲 Displace✅ 直接做
feDisplacementMap —— 即 PS「置换/波纹」；液化是它的交互可控版（见第 4 页）
高斯模糊 Gaussian Blur✅ 直接做
feGaussianBlur 或 CSS blur()
