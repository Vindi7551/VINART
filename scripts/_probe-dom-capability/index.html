DOM 表达力探针 —— 这四个，HTML/CSS/SVG 到底行不行？

同一条管线、同一个 Chromium 渲染。上排 = 你举的两个例子；下排 = 一个正例 + 一个诚实的负例。
A · 字体「涂鸦 / 做旧」质感DOM 可以
做法：SVG 滤镜 feTurbulence + feDisplacementMap 位移字形边缘 → 毛糙、手绘感的笔画。 不需要换涂鸦字体文件，也不必转成图片。
B · 图片边缘的笔刷 / 撕裂效果DOM 可以
做法：一个被湍流位移过的矩形当 mask，图片套上它 → 边缘变成不规则的「笔刷 / 撕裂」轮廓。 全程在 DOM 内渲染。
C · 文字笔画内填纹理 / 图案DOM 可以
TEXTURE
做法：background-clip:text —— 把文字当蒙版，任意渐变 / 图案 / 照片都能填进笔画内。
D · 沿路径的「粗细变化」笔触DOM 原生不行
SVG 的 stroke-width 沿线恒定——一笔里「由粗到细」写不出来。 要做得先算出变宽轮廓（几何计算）再填充；这正是光栅 / 几何引擎的活， 不是 DOM 能直接给的。
